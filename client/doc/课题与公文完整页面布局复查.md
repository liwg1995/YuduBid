# 课题与公文完整页面布局复查

2026-10-30，design。

## 范围

实际GrantApplicationPage申报书入口、OfficialDocumentDraftingPage润色入口、AppProviders与产品样式；隔离桥接数据：长正文80段、课题四阶段工作稿、背景模块内容，公文长草稿和成功任务。桥接未访问用户工作区，未执行真实生成/导出。四主题×1280/800px×两页16个完整Renderer页面检查，另补四个修复后布局测量。

## 发现与修复

- 课题页面内部滚动布局下，800px流程导航因flex默认shrink压缩到clientHeight=0、scrollHeight=44。modern-grant-journey设置flex-shrink:0；修复后1280与800px均68px，流程按钮可正常呈现。
- 公文润色历史面板在自动网格行上设置height:100%，造成百分比高度与轨道尺寸相互约束。历史区clientHeight44px、scrollHeight227px。检查/润色面板改height:auto；修复后两档窗口历史区227px、scrollHeight227px。长正文仍在工作台内部滚动，未依赖body滚动。

## 验证与边界

16组初始页面均无横向或body纵向溢出，现代两页无大面积近白背景命中（RGB各通道>215，alpha>.5，宽>100高>30）。修复后四次测量无横向/body滚动，正文和历史区内容高度正常；没有将两处布局故障掩盖成通过。npm run build与git diff --check通过。
