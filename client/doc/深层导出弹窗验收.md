# 深层导出弹窗主题与滚动验收

日期：2026-10-29；design分支，累计修改保持未提交。

## 范围与改造

延续Ant Design的信息层级/暗色舒适性原则以及仓库主题变量、内部滚动和复用约定，本轮聚焦售前与软著的深层界面。

- 售前项目包预览头/正文/底栏及PPT导出进度头仍有硬编码浅色表面，替换为主题变量。导出成功路径按钮去除浅色渐变、重阴影，标题/路径改为主题文字色；中文长路径可换行。PPT进度弹窗在内容超过视口时允许内部滚动。
- 软著正式导出核对中的信息格、摘要区、导出标签及说明改用主题表面与文字。共用标题样式同时修正合规提醒的标题/说明，合规正文表面沿用主题变量。
- 软著确认弹窗使用固定标题/底部操作、中部内部滚动。软件全称独占一行并完整换行，其他信息用三列，窄窗口为两列，避免长名称把四个格子都拉成大块。
- 从原工作台内联JSX提取SoftwareExportConfirmDialog和PresalesPackagePreviewDialog，以便使用实际组件做独立主题/长内容验证。调用方继续提供全部业务状态与回调；文案、导出资格判断、模型/IPC、真实文件处理保持原逻辑。售前Markdown继续allowRawHtml=false。
