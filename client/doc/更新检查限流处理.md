# 更新检查限流处理

2026-10-30。

截图中的app:get-latest-version错误来自GitCode Release API返回429。代码此前并发读取GitHub/GitCode，并要求版本产物及校验值同步；任一源失败会抛出IPC异常。启动自动检查与设置手动检查共用同一入口，但此前没有合并请求/缓存。代码证实可能重复请求，不据此断言本机请求就是上游限流的唯一原因。

新增services/releaseMetadataService.cjs处理元数据网络请求，IPC调用该服务。按来源和URL合并进行中的请求，成功缓存5分钟；429遵守Retry-After秒数或HTTP日期，缺失默认60秒，冷却范围1秒至24小时；冷却期明确报错且不重发，不把旧缓存当最新成功。网络/解析失败不缓存，下次允许重试；GitCode404保持同步未完成语义。限流日志记录HTTP状态和retryAt，使用warn；IPC仍会reject，因此Electron仍可能打印handler错误，不能以消除所有错误日志为完成标准。未降级双源同步、来源白名单或SHA256校验，未修改IPC契约。

验证：node scripts/verify-release-metadata.cjs覆盖10调用并发、5分钟缓存、429不重复请求与到期恢复、网络失败重试、404、Retry-After日期/非法/缺失。npm run verify:update-integrity通过；两个CJS语法检查、npm run build与diff检查通过。npm run dev使用/tmp/yibiao-update-check-smoke-20261030隔离目录，实际原生窗口显示欢迎页；未触发真实远端更新检查，以免额外消耗服务配额。临时实例停止后清理隔离目录。
