# 软著、售前跨进程持久化与整页验收

日期：2026-11-01；分支：design。保持累计工作未提交，未推送、未发布。

## 本批修复

售前工作台材料预览以前只在读取成功后替换内容：选择乙材料读取失败时，甲材料正文仍可能停留在预览区。本批改为按项目 ID 和材料 ID 标识预览请求，切换立即隐藏旧内容；增加加载、错误说明和“重试读取材料”。过期请求的成功/失败回调不再修改当前预览或弹出错误提示。调试日志只记录项目/材料标识与错误，不记录正文。

初始加载改为 Promise 链捕获服务缺失和同步异常，页面卸载后不再更新加载错误或弹 Toast。生图模型状态异常独立降级为不可用，不阻止项目资料加载。

## 真实磁盘验证

新增命令：`cd client && npm run verify:software-presales:persistence`。

脚本使用三个独立 Electron 进程、中文临时用户目录，执行实际 Main 服务，不调用模型。只有生成材料初始样本通过文件夹具建立，之后的保存、清空、项目切换、版本比较和恢复调用生产服务。

- 写入进程：软著手册修订及保存前备份，申请表独立内容与清空；乙项目无甲项目草稿。售前甲乙项目各保存分析、调研、架构、图表、汇报五类成果。
- 恢复进程：重新读取修订稿、空申请表和两个项目的成果；恢复手册旧版本，检查恢复前备份及确认/导出状态失效；清空售前甲项目分析成果。
- 第三进程：确认恢复后的手册与清空后的售前成果保留；拒绝重复恢复及非法版本 ID；再次检查项目隔离。

三进程全部通过。临时业务目录结束后删除，无用户真实项目改动。日志：`/tmp/yibiao-material-persistence-20261101.log`。

这属于 Electron 运行时真实磁盘服务验证，不代表 Renderer → preload → IPC 全链路或原生鼠标保存/恢复已验收。
