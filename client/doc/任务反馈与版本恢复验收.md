# 任务反馈与软著版本恢复验收

日期：2026-10-28，分支：design。

依据：[Ant Design 反馈](https://ant-design.antgroup.com/docs/spec/feedback-cn)、[对话框](https://ant-design.antgroup.com/components/modal-cn)，结合开发说明的主题变量、共用控件、后台任务权威状态及中文反馈要求。

## 实际改动

- BusinessTaskProgress 与 TaskProgressSummary 统一进行中、已完成、失败文字。经典/柔光/暗黑原生进度条仍保留，补充成功/失败颜色；现代外观继续使用 Ant Design Progress。状态文字提供颜色以外的信息。
- 抽取百分比展示规范化：有限数字取整并限定0–100；未知数值保持未知。运行中无百分比使用原生不定进度，完成/失败无百分比只展示状态，不再误报“等待阶段反馈”，也不补造0%或100%。
- 可研真实 AnalysisTaskFeedback（分析、参数、目录、正文共用）和Word导出接入BusinessTaskProgress；暂停/停止无数字时保留任务标题，不添加“等待”状态。项目协作现代流程栏的全套导出补齐成功/失败状态传入。
- 追踪调用后确认TaskProgressCard为未接入页面的旧展示组件，本轮未改该文件，不以其孤立表现代表真实可研页面。实际页面原有暂停/停止标题保留。
- 软著DraftVersionHistory：切换版本时清除旧比较结果、显示正在比较并禁止恢复；选中项提供aria-pressed；恢复中锁定选择、Esc、遮罩和关闭/取消按钮，成功结束后正常关闭；原外部disabled也约束最终确认。
- 软著版本列表与差异预览恢复主题表面和文字，暗色增删差异保留独立语义颜色；窄屏版本目录置于预览上方，列表内部滚动。恢复弹窗说明和操作区增加现代外观24px左右内边距。

## 验证

- 真实组件、样本React状态或模拟bridge，不读取真实用户项目。
- 四外观 × 1040×850、420×700，共8组任务反馈组合：有限百分比36/100显示一致；未知失败/完成没有百分比，未知运行原生progress不带value；无页面横向溢出。暗色状态文字使用较亮颜色。
- 可研七状态running/pausing/paused/stopping/stopped/success/error检查，错误无百分比展开后展示失败、保留已保存结果提示和最近7条日志。暂停停止仍保持原状态标题。最终七状态已重新检查并更新状态JSON，暂停/停止未知进度不再添加“等待”提示。
- 软著异步样本：切换至v1时显示正在比较、旧v2差异不可见、恢复按钮不显示；比较结束显示v1内容。模拟恢复期间按Esc后弹窗仍在，关闭和取消禁用；模拟完成后关闭。没有执行真实恢复或写用户资料。
- 软著四外观 × 两档窗口共8组合：经典/柔光白色主题表面；暗黑rgb(21,29,45)、现代rgb(22,31,48)，420窗口为单列且弹窗边界20–400px，按钮在窗口内。现代说明实际文本左右24px内边距（p元素边框本身仍占满对话框宽度）。
- npm run build 与 git diff --check通过；仅既有chunk体积警告，无依赖、Main、IPC修改。
