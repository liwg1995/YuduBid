# 项目列表统一设计验收（2026-10-28）

## 设计依据与结论

同类项目索引共用布局、字阶、检索、时间展示和行操作；业务字段依实际任务保留。技术方案原来的行列表与可研报告表格没有形成统一组件，本轮统一到 Ant Design Table。排序信息使用箭头和排序状态表达，排序列正文背景与普通单元格一致，不再出现整列灰色竖条。

依据：[Ant Design 设计体系](https://ant-design.antgroup.com/docs/spec/introduce-cn)、[Table 官方组件与设计变量](https://ant.design/components/table-cn/)、仓库 client/开发说明.md。design-taste-frontend 技能仅采用现状审查、品牌延续、字体间距收敛的方法；该技能明确不针对密集数据表格，表格实现遵循现有框架与 Ant Design，不引入 Tailwind 或新依赖。

## 八大模块盘点

| 模块 | 项目索引处理 | 保留差异 |
| --- | --- | --- |
| 售前工作台 | 接入共享列表 | 客户、阶段、资料数量及右侧资料编辑区；窄内容区上下排列 |
| 招投标 | 技术方案/已有方案扩写共用索引、可研索引接入 | 历史项目、当前项目、可研步骤和正文小节 |
| 公文写作 | 无独立项目索引 | 写作、检查、润色、模板和历史工作区不强制改为项目表 |
| 课题申报 | 接入共享列表 | 原有内联重命名、分页和删除确认 |
| 项目协作 | 项目管理索引接入 | 批量选择、客户/类型/项目组/交付方、流程进度；历史主从页面保留 |
| 论文导师 | 无独立项目索引 | 导师工作台与历史记录保留其任务结构 |
| 软件著作 | 接入共享列表 | 软件版本、状态、源码路径、复制、归档及恢复 |
| 专利生成 | 接入共享列表 | 类型/阶段筛选、草稿数量、详情抽屉、归档 |

本轮是七个项目索引视图统一，不表示八大模块全部工作区重新设计完毕。

## 共享实现

- shared/ui/ProjectList.tsx：页头、搜索工具栏、表格、时间格式与进入/更多操作。
- shared/ui/projectList.css：20px 标题、14px 正文、12px 次要信息，32px 控件、16px 区块间距、360px 搜索框。表格内部横向滚动，操作列固定右侧。
- EnterpriseUiProvider：Table 的 headerSortActiveBg 与 headerBg 相同，bodySortBg 与 colorBgContainer 相同；保留排序图标和键盘排序。
- 沿用各模块业务回调、已有分页/筛选和经典外观分支，没有修改 Main/preload 或项目存储。

## 本轮证据与边界

- design 分支；保留全部未提交修改。
- npm run build 通过（tsc --noEmit + Vite，9.45s，仅既有 chunk 体积警告）；git diff --check 通过。
- 真实 Renderer 组件 + ModernShell/AppProviders，使用 21 条合成项目及模拟 window.yibiao API，不读取用户项目、不调用模型、不测试真实磁盘 CRUD。
- 七个索引搜索 21 均得到一条结果；清除恢复。标题20px、搜索360px；排序列与普通正文单元格背景一致。
- 七页在1040及1440宽度下无页面横向溢出，默认1280界面亦观察。售前列表窄区改为上下布局，软件源码路径列内部横向滚动。
- 技术方案排序切换、更多菜单方向键进入/Escape返回来源、内联重命名回调通过；软著当前项目归档禁用状态保留。
- 售前、课题、项目协作、软著、专利五种经典外观分支，在 classic/aurora/dark 三主题下仍显示项目、未进入现代共享表格。这是组件分支冒烟检查，不等同三主题全应用导航与全部业务操作验收。
- 临时验收入口移除；复用用户既有 Vite，不停止它。
