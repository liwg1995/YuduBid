# 启象 UI 设计约定

依据 Ant Design 的设计价值观、全局样式、设计原则、页面模式与组件文档，结合本地文档生产工具的工作场景。规范中的建议需要按业务应用，不等于把所有页面替换成 Ant Design 默认外观。

## 设计理念

- 自然：围绕“准备资料、处理、校对、交付”组织界面，优先让用户读懂内容，避免用界面装饰占据工作空间。
- 确定性：相同操作沿用相同组件、命名、位置和反馈。业务完成状态来自 Store 与后台任务，不由当前浏览位置推断。
- 意义感：让用户知道正在处理什么、完成了什么、接下来能做什么；不重复展示用户已经知道的说明。
- 生长性：抽象共享控件和页面结构，随着内容和模块增加保持可扩展性。

来源：[设计价值观](https://ant.design/docs/spec/values-cn/)、[设计模式](https://ant.design/docs/spec/overview-cn/)。

## 空间与排版

- 主体字号 14px、行高 22px，辅助信息 12px，局部标题 16px，页面标题 20px。通常使用 400 / 500 字重。
- 间距优先使用 8 / 16 / 24px；同组信息靠近，不同组之间拉开距离。
- 主工作区随空间变化；不要同时固定并排显示业务导航、阶段导航、章节树、编辑器与详情五个区域。
- 目录初始宽度 320px，桌面模式最小 280px，可拖动分隔条调整。长标题换行，保留编号和层级关系。
- 工作区不足 720px 时改为上下分隔；宽度阈值按工作区测量，而非仅按窗口宽度推断。
- 输入控件通常高 32px，局部紧凑筛选可使用 28px。不能靠缩小正文字号补偿错误的空间分配。
- 长内容在目录、正文或表单内部滚动，保留 `min-height: 0`。

320px、280px 和 720px 是启象的场景取值，Ant Design 并未规定这些尺寸。

来源：[布局](https://ant.design/docs/spec/layout-cn/)、[字体](https://ant.design/docs/spec/font-cn/)、[亲密性](https://ant.design/docs/spec/proximity-cn/)、[对齐](https://ant.design/docs/spec/alignment-cn/)。

## 导航与信息层次

- 保留当前位置与返回入口，减少重复的面包屑、阶段标题和大型说明。
- 七阶段流程使用按需打开的竖向阶段列表，当前阶段始终显示；不把七个步骤硬塞进窄横向步骤条。
- 正文工作台使用“目录 + 阅读/编辑器”；次要章节详情按需展开。
- 全局事实默认单栏编辑，按需切换预览或对照；视图切换保留当前草稿，窄工作区的对照按上下布局显示。
- 目录编辑列表以编号和标题为主，完整描述放入详情；排序、全部展开和全部收起归入更多操作。
- 设置中并列的六个领域使用页内 Tab。Tab 表示信息分类，流程导航表示前后依赖，不混用语义。
- 空闲目录不显示常驻任务说明；执行任务时才展示简洁阶段信息。
- 首页保留业务空间入口，不添加最近项目区域。

来源：[导航](https://ant.design/docs/spec/navigation-cn/)、[足不出户](https://ant.design/docs/spec/stay-cn/)、[简化交互](https://ant.design/docs/spec/lightweight-cn/)、[详情页](https://ant.design/docs/spec/detail-page-cn/)。

## 组件选择

| 场景 | 组件或模式 | 约束 |
| --- | --- | --- |
| 章节导航 | Ant Design Tree | 受控选中和展开；搜索保留父级路径；不改动权威目录数据 |
| 目录与正文空间分配 | Ant Design Splitter | 可调宽度；窄工作区上下布局；调整布局不丢弃编辑内容 |
| 项目数据管理 | Ant Design Table | 排序、筛选；数字右对齐；不足一页时隐藏分页 |
| 项目详情 | Ant Design Drawer | 保留列表上下文；标题清楚；支持关闭与焦点回归 |
| 业务阶段导航 | Radix Popover + 竖向阶段列表 | 当前阶段可见；状态来自业务结果；保留原有跳转校验 |
| 确认和危险操作 | 现有 Radix Dialog | 明确后果；沿用项目共享实现 |
| 短暂操作反馈 | 现有 ToastProvider | 不再新增第二套全局 Message |
| 表单分类 | 页内 Tab | 键盘方向键切换；标签与面板关联 |
| 低频设置 | 可展开高级设置 | 默认值不改变；展开入口可发现 |

Ant Design 控件统一通过 `shared/ui/EnterpriseUiProvider.tsx` 配置中文、品牌色、字阶和圆角。守矩继续沿用原有主题及控件。新增组件前先检查现有共享层，避免重复封装。

来源：[Tree](https://ant.design/components/tree-cn/)、[Splitter](https://ant.design/components/splitter-cn/)、[Table](https://ant.design/components/table-cn/)、[Drawer](https://ant.design/components/drawer-cn/)、[数据展示](https://ant.design/docs/spec/data-display-cn/)。

## 交互与反馈

- 每个按钮区最多一个主按钮；编辑/保存靠近正文，视图控制靠后，低频操作进入更多菜单。
- 保存中禁止重复提交，保存失败保留草稿并显示可操作提示。
- 表单错误紧邻字段，保留至修正；不要只依赖短暂 Toast。
- 切换章节或离开工作区时保护未保存修改。
- 区分任务阶段、章节计数、步骤位置和任务进度，不用步骤序号冒充任务完成百分比。
- 空闲时不展示重复的“生成统计 + 0%”；仅保留一组已完成小节数量。任务阶段进度统一使用 `TaskProgressSummary`（Ant Design Progress），阶段说明在上、线性进度与固定宽度百分比在下，百分比使用等宽数字、右对齐且不换行。
- 同一区域不重复显示相同含义的计数或百分比；无法计数的阶段不拼出 0/0。
- 无有效进度时使用不确定进度；空状态解释原因并提供可行操作。
- 短暂、明显可见的视图变化不重复弹成功提示；动画服务于反馈，尊重减少动态效果偏好。

来源：[按钮](https://ant.design/docs/spec/buttons-cn/)、[反馈](https://ant.design/docs/spec/feedback-cn/)、[即时反应](https://ant.design/docs/spec/reaction-cn/)、[表单页](https://ant.design/docs/spec/research-form-cn/)、[空状态](https://ant.design/docs/spec/research-empty-cn/)、[动效](https://ant.design/docs/spec/motion-cn/)。

## 色彩与验证

启象保留深色与紫色品牌。背景、边框、说明使用语义变量；主色用于关键行动与选中状态，成功、失败颜色保持一致。避免大面积高饱和色和无目的阴影。经典、柔光、暗黑的守矩样式应不受启象局部调整影响。

每轮检查普通与专注模式、长章节名称、空目录、无搜索结果、失败筛选、未保存保护、工作区宽度变化及键盘操作。通过 TypeScript 和 Vite 构建后，在 Electron 验证实际布局。不能仅因组件 API 正确就判定界面可用。

来源：[色彩](https://ant.design/docs/spec/colors-cn/)、[暗黑模式](https://ant.design/docs/spec/dark-cn/)、[阴影](https://ant.design/docs/spec/shadow-cn/)。


## 表单选择与轻量弹窗

- 弹窗参照 [Modal](https://ant.design/components/modal-cn/) 的标题、内容、操作区层次；保留 Radix 的焦点约束和 Esc 行为。启象轻量弹窗标题 16px / 24px、正文与按钮 14px / 22px，使用 8 / 16 / 24px 间距，操作按钮靠右。
- 参照[数据录入](https://ant.design/docs/spec/data-entry-cn/)区分字段名称、选项和帮助说明；单选卡片使用原生 radio，支持 Tab、方向键及空格，选中状态与键盘焦点分别表达。选项名称保持 14px，辅助说明最低 12px。
- 危险确认打开时默认聚焦取消；重命名输入打开时选中原值。弹窗高度受视口约束，长内容在弹窗内部滚动。通用弹窗与输入表面使用主题变量。
- 保存状态通过 status 区域播报，错误紧邻相关字段；为表格需求、配图参数等控件提供明确的可访问名称。


## 技术方案项目列表

- 依据[数据列表规范](https://ant.design/docs/spec/data-list-cn/)采用列表布局，突出项目名称与更新时间。顶部保留“创建项目”主操作，搜索、排序和结果数量组成列表工具栏。
- 项目标题可进入工作区；“更多”使用 Ant Design Dropdown，收纳重命名与删除。当前项目用文字标签表达，不依赖整行边框颜色。
- 无项目、无搜索结果、读取失败分别提供创建、清空搜索、重新读取操作。不可恢复的删除通过统一确认弹窗说明项目名称和删除范围。
- 创建、切换、重命名、删除期间禁止重复提交；创建有等待文案，重命名支持 Enter 保存和 Esc 取消，输入自动选中原名称。列表内部滚动，长名称省略并可查看完整标题。


## 文件准备与招标解析

- 上传页将文件状态、名称、解析方案、字数和文件操作放在同一区域，预览独立滚动；替换文件影响后续成果时，在文件操作附近说明影响。等待文案对应实际导入对象，不把未操作的文件按钮统一标成“解析中”。
- 解析策略放在页首，使用原生 radio；任务导航与结果阅读构成双栏。参考[数据展示](https://ant.design/docs/spec/data-display-cn/)按重要程度与关联编排信息，减少重复的“解析结果”标签。
- 解析统计分别展示已成功、失败和未结束数量；进度表示已结束的任务比例，不将失败任务描述为成功。运行和失败时复用标准进度摘要，全部成功时显示结果和下一步指引。
- 失败说明与重试操作相邻；有历史结果时明确提示保留的上次结果。复制操作失败通过 Toast 反馈。窄窗口转为纵向布局，滚动限制在页面内部。
- 标题 20px、阅读区标题 16px、主要文案与控件 14px、辅助信息 12px；控件间距使用 8 / 16 / 24px。


## 扩写范围与导出选择

- 扩写目录使用 Ant Design Tree 的复选、半选与展开行为；长标题换行，支持名称/编号搜索。搜索中勾选只修改可见小节，保留被隐藏的选择；无正文节点不可勾选，并提供返回正文生成的入口。
- 扩写目标和表格参数直接展示；并发及一致性检查放入高级设置。任务采用统一进度摘要，启动请求有等待状态和重复提交保护；正文生成完成不会被描述为“所选小节已扩写完成”。
- 导出弹窗明确区分标题、内容和底部操作区，只有内容区滚动。配置未读取成功时不展示未核实的选项，失败提供重新读取按钮。
- 模板检索只筛选选项，不自动切换已经明确选择的模板；当前模板单独标出。确认导出使用该选择，并拦截重复提交。用户界面使用“优化排版”，技能标识保留在内部配置中。


## 后台任务与轻量通知

- 后台任务使用 Radix Popover，支持碰撞避让、Esc 关闭及焦点恢复。标题和页脚固定，任务记录在面板内部滚动。
- 任务按 task ID 区分，展示所属项目；运行、待确认、暂停、失败和结束分别表述。读取快照前订阅事件，快照完成后回放期间的新事件，避免旧快照覆盖更新。
- 未知进度使用不定进度条，不伪造百分比。失败原因直接展示，最近日志按需展开；结束记录可手动清除，此操作只影响本次面板展示。
- 读取失败有持续说明和重试入口，仍保留已收到的更新。任务状态通过文本与颜色共同表达，避免仅靠圆点颜色。
- 轻量通知正文使用 14px / 22px，操作按钮高度至少 32px，使用带语义的状态图标；装饰图标从可访问名称中隐藏，避免重复播报。重要错误保持前景播报，一般通知使用背景播报。


## 设置中心

- 设置分类保持纯中文名称，去掉无业务含义的编号、英文标签和跳转箭头。宽窗口保留分类栏，内容区域内部滚动；窄窗口分类横向滚动，表单纵向排列。
- 页标题 20px / 28px、分区标题 16px / 24px、字段名称和控件 14px / 22px、辅助说明 12px / 20px。宽表单标签与控件对齐，开关和行内操作保留同行。
- 尚未读取到配置时展示加载或失败状态，不显示“已保存”或可编辑的占位配置。失败可重新读取；保存中显示等待状态并阻止重复提交与分类切换，保存失败持续显示原因并保留修改。
- 组合输入框跟随当前主题表面，密码显隐与辅助按钮保持 32px 控件规格；密钥输入有独立可访问名称。所有真实配置仍由现有 Main 存储流程保存。

### 知识库文档列表

- 依据 Ant Design「数据列表」「数据展示」：文件夹负责分类，标准 Table 负责浏览；搜索与状态筛选位于结果上方。
- 文档标题进入原文，知识条目作为常用操作，删除与调试收进更多菜单。候选条目、block、文档 ID 仅开发者查看。
- 完成、失败显示语义标签；处理中显示实际进度；未知进度显示等待说明。失败原因直接可见，长文件名允许换行。
- 20 条一页，单页不显示分页器；空库、空文件夹、筛选无结果、读取失败分别说明并提供下一步。
- 主标题 20/28、分区 16/24、正文 14/22、辅助 12/20；文档/图片分类由装饰卡片改为轻量导航。

### 本轮覆盖与验收边界

资料管理、投标检查、可研全流程及其余写作/申报/协作/专利业务已落实本轮界面改造，范围与证据见 `UI全模块验收记录.md`。后文保留各阶段规范，不以早期阶段计划覆盖当前状态。

- 采用 Ant Design 的自然、高效、一致反馈原则，以及字体、间距、数据录入、数据展示、Tree、Table、Pagination、Progress 等规范；保留启象紫色品牌和现有 Radix 弹窗。避免因引入规范而强制替换所有基础组件。
- 已完成隔离模拟界面验证与构建；真实 Electron 文件选择、落盘、模型生成、图片转换及 Word 内容回归仍需独立验证。不能据此宣称全应用真实业务已通过验收。
- 不添加最近项目入口，不新增统计/上报/远程公告；Renderer 继续通过 window.yibiao 访问业务服务。

### 图片素材与知识详情闭环

- 图片继续使用适合视觉浏览的卡片网格，缩略图负责预览，编辑按钮负责修改元信息；原图按需读取，使用 Ant Design Image 查看器提供缩放、旋转及退出操作。
- 原图读取、图片列表读取、搜索无结果和空文件夹分别反馈；读取失败提供重试，单张缩略图失败不阻断整批素材。异步结果按文件夹与查询隔离，避免旧请求覆盖当前列表。
- 图片编辑采用 Radix Dialog，正文滚动、底部操作固定；保存期间禁用重复提交及关闭，失败保留草稿并固定显示错误。关闭后恢复编辑入口焦点。
- 图片选择器复用同一加载逻辑，补充分类/搜索的无障碍名称、加载/错误/空状态和清除搜索；原比例呈现缩略图，避免架构图裁切。
- 启象文档详情打开时保留列表实例，返回后保留搜索、状态筛选、排序、分页和滚动位置，并恢复来源按钮焦点。进入详情聚焦文档标题；读取失败可重试，不显示成“暂无内容”。
- 资料管理下一批转入模板管理、资信库；图片批量操作和复杂原文的跨主题、窄窗口整体回归仍属于最终统一验收范围。


### 模板管理与资信库列表

- 模板使用目录与预览的主从布局。目录提供名称搜索、系统/自定义类型筛选，筛选不改变当前预览；若当前模板不在结果中，明确提示预览已保留。
- 系统模板保留复制入口，自定义模板的编辑、导出、删除进入更多菜单。菜单支持 Escape 并回到触发按钮；删除优先聚焦取消，失败保留模板与对话框错误。
- 模板编辑期间保留列表实例，返回后刷新数据、保留搜索/筛选/选择及浏览位置，读取完成后恢复来源模板或搜索框焦点。
- 企业使用标准 Table，支持名称搜索、更新时间排序和 20 条分页。企业名称进入详情，窄内容区固定右侧操作列，横向与纵向滚动限定在列表内部。
- 企业搜索、分页、排序和滚动位置由页面持有，进入失败及从详情返回均恢复；进入成功聚焦企业标题，返回聚焦来源企业。
- 加载、加载失败、搜索无结果、真实空库分别反馈；创建/删除失败在对话框内保留错误，创建成功但进入失败时提示重新进入，不重复创建。
- 模板和企业写操作使用本地互斥防止重复提交；模板删除必须在服务明确返回成功后更新列表。
- 本阶段覆盖列表与返回闭环。模板编辑器复杂表单与资信库员工/业绩内页已在后续阶段落实；真实文件操作及全应用回归仍在后续清单中。


### 资信库内页与记录表单

- 企业基本信息采用统一的 14/22 正文、16/24 分区标题及 16/24 间距，控件与资料栏目遵守主题色；侧栏移除装饰序号与箭头，使用垂直 tablist，支持上下方向键和 Home/End。
- 员工/业绩使用 Ant Table：名称进入编辑、名称排序、20 条分页、结果计数、区分空数据与搜索无结果，并提供清除搜索。右侧删除列固定，宽表在内容区内横向滚动。
- 企业字段保存失败后保留输入与持续错误说明，提供重新保存入口。失败字段分别记录，成功保存无关字段不会掩盖其他失败；失败状态使用错误色。
- 记录保存、删除使用互斥保护；保存期间字段禁用，错误在弹窗内持续显示，保存失败保留草稿。编辑与删除关闭后恢复来源焦点，来源已消失时回到搜索或当前分类。
- 编辑器通过独立滚动容器包裹原生 fieldset，避免 fieldset 的尺寸行为导致表单覆盖底部按钮；标题、错误与底部操作保持可见。
- 证明材料栏目、上传区域与图片项跟随主题，缩略图保留完整比例；上传和移除按钮的无障碍名称包含具体栏目或资料名称。
- 以上为 UI 展示与反馈改造；未修改资信库 Main 存储、业务契约或图片上传协议。


### 模板编辑器复杂表单与预览

- 遵循 Ant Design 表单的清晰分组、就近反馈及避免重复确认原则：模板名称与其他参数统一保存，去掉仅确认名称的额外步骤；空名称明确说明并聚焦对应字段。
- 宽内容区并列呈现设置与预览，分别内部滚动；窄内容区切换“参数设置 / 排版预览”，保留已输入内容。分类优先使用业务名称，不添加装饰序号。
- 设置正文 14/22、辅助 12/20，常规控件至少 32px，间距使用 8/16；导航、预览框和操作栏使用一致的边界层级。
- 读取失败可重试；保存失败保留草稿及持续错误；保存期间禁用修改、重复保存与离开，完成后才显示已保存。各外观均提示未保存离开，默认聚焦取消。
- 预览标明示例内容及 Word 最终效果边界；全屏预览退出恢复来源焦点。导出反馈复用统一进度组件。
- 不改模板存储与 Word 导出契约；真实 Word 效果仍需实际导出验证。


### 标书查重输入与结果

- 按「亲密性」使用 8/16/24 间距组织文件、说明及操作；文件为主、辅助说明为次，窄内容区让辅助说明后置，维度导航横排。
- 按「即时反应」分别反馈读取、文件调整、启动、运行和导出；持久错误与原数据同时保留，用户可明确选择重试。读取失败不展示成空工作区。
- 等待、运行、成功、失败分别呈现；百分比仅说明实际处理进度，不因失败自动填为成功满条。只有成功完成的空结果才可显示“未发现重复”。
- 任务及文件操作互斥，后台任务仍由 Main 管理；页面返回时恢复失败说明，重试由用户主动触发。
- 对照表固定列头及元数据项，横向滚动留在表格内；相同值和同日日期除了颜色，还通过文字图例说明。暗黑主题使用深色表面及可读的语义色。
- 结果分页保持数量与翻页操作清晰，单页隐藏无效翻页按钮；图片不裁切，普通用户界面使用业务名称。
- 工具条参与内容区布局，不遮挡结果；确认弹窗默认聚焦取消，关闭时恢复原触发元素。


### 暗标检查四步流程

- 步骤导航表达当前位置，不能用“已浏览”推断任务完成；检查、复核、修复成功与否以 Main 状态为准。
- 可用内容宽度决定规则分类侧栏/横排与字段列数；标题 20/28、分区 16/24、正文与字段 14/22、辅助 12/20，间距采用 8/16/24。
- 已知进度复用标准进度组件并保持百分比对齐；AI 复核没有可靠百分比时使用等待说明与已运行时间，不显示固定估算值，不使用装饰动画代替任务状态。
- 规则执行失败时持续给出原因；空结果限定已完成的检查范围，不对未执行/失败规则宣称无问题。尚未检查的修复项显示“待检查”。
- 问题标题、风险、人工确认、计数分层；长标题和位置保留可读性，展开后以招标要求、问题说明、修改方法、出现位置组织详情。
- 分类与修复筛选支持方向键、Home/End 及单一 Tab 停靠，展开按钮关联详情。命名失败在弹窗内保留输入和错误，关闭后恢复来源焦点；异步导出显式记录来源按钮。
- 保持上游完整流程共用及 Main 权威存储，不通过样式或统计显示修改规则结论。真实检查、修复及导出文件效果在最终实际文件回归中验收。


### 废标项检查输入、解析与结果

- 页签表达维度状态，不能根据阶段文案虚构百分比；只有 Main 返回的实际任务进度显示数值，失败不以满进度冒充成功。
- 输入区先组织文件及操作，再呈现阅读器；窄内容区使用内部纵向滚动，文件区域不能被后续面板压缩覆盖。长文件名可换行或用单行省略及完整标题提示。
- 结果页合并重复标题，风险与待处理事项分层呈现；较长的待处理清单可展开阅读，分类横向滚动，让证据和建议获得主要阅读空间。
- 工作区读取、项目来源读取、文件调整、配置保存和导出均区分等待/成功/失败；失败保留原数据和可见说明。空列表不能替代读取失败。
- 重置在成功返回前保留原工作区；配置保存成功后才显示已保存。等待时禁用相冲突操作，关闭弹窗回到来源控件。
- 专项检查失败明确显示未完成和重试入口；没有完整结果时风险数量为待确认，不能以零代表无风险。判定与输入签名规则保持原业务逻辑。
- 标题 20/28、分区 16/24、正文和字段 14/22、辅助 12/20；控件至少 32px，间距用 8/16/24。经典和启象外观共用证据、状态与可访问交互规则。


### 可研项目列表与基础资料

- 项目管理复用标准 Table：名称是进入入口，搜索、排序、20 条分页和结果计数服务浏览，低频操作收进更多菜单；长列表分页保持可见。列表与工作区之间保留查询、排序、页码、浏览位置和来源焦点。
- 新建、重命名和删除采用统一弹窗，明确必填、等待与失败；名称失败保留输入、删除失败保留项目，危险操作默认聚焦取消。来源被筛选移除后回到搜索。
- 工作区读取失败提供重试，不将错误显示为读取中或已同步；步骤切换只有在 Main 保存成功后更新，不按浏览位置推断生成完成进度。
- 基础资料表单保存失败保留草稿，保存中禁用字段及离开；各外观统一未保存保护。原生 fieldset 置于独立滚动容器，底部保存操作不与覆盖工具条重叠。
- 根据可用内容宽度组织步骤导航与字段列数，使用既有 20/28、16/24、14/22、12/20 字阶和 8/16/24 间距；主题颜色来自 --yb-*。
- 项目步骤和生成业务契约保持原实现；其余可研面板及真实模型生成、文件解析、Word 导出须分别验证，不能据本阶段声明完整可研流程已验收。


### 可研资料文件与分析

- 依据 [反馈](https://ant.design/docs/spec/feedback-cn/)、[足不出户](https://ant.design/docs/spec/stay-cn/)及 [Progress](https://ant.design/components/progress-cn/)，文件读取失败就地重试，切换文件不可残留上一份内容。错误、加载、无内容分别表达。
- 文件列表和阅读器按内容区宽度分配；不足 720px 使用原生选择控件，把阅读空间留给资料。当前文件的移除放在阅读标题附近，失败保留文件，变更前明确下游影响。
- 分析默认阅读，源码和对照按需切换；编辑/对照保留同一草稿，保存成功后才退出，失败提供持续错误并保留内容。未保存离开和保存中锁定适用于经典及启象。
- 阶段估算明确标注，不当作报告完成率；空闲无 0%，任务失败保留原因和重试，详细过程按需展开。手动编辑时让出任务卡空间。
- 阅读、编辑及预览表格均使用主题变量；避免固定最小高度挤压可用空间。宽屏左右对照，窄屏上下对照且每区至少 180px，在对照区域滚动。所有 AI Markdown 继续禁用 raw HTML。


### 可研报告目录

- 依据 [Tree](https://ant.design/components/tree-cn/)、[数据录入](https://ant.design/docs/spec/data-entry-cn/)及[反馈](https://ant.design/docs/spec/feedback-cn/)，目录树突出编号与长标题，说明放在详情；搜索保留父路径和原有展开上下文。窄工作区切换目录/详情，避免三栏同时压缩。
- 手动编辑、添加、删除统一为目录草稿，保存/撤销入口始终可见；取消不得只关闭编辑而留下未说明的修改。切换章节保留草稿，离开保护覆盖步骤、项目列表和全局导航。
- 目录保存失败保留草稿，成功后才更新权威状态；保存前说明下游清空范围，提交时不能带回旧正文。限制三级目录，空标题和空目录就地校验。
- 生成设置取消应放弃配置草稿或询问；配置未变时不调用会清空目录的保存接口。参考库空状态、读取失败、不可用选择各自表达，按组选择和搜索保留隐藏选择。
- 生成与调整的清空时机分别以 Main 行为为准，不用统一文案掩盖差异；启动等待与后台运行分开反馈，阶段估算明确标注，成功过程默认折叠。


### 可研关键参数

- 依照 [反馈](https://ant.design/docs/spec/feedback-cn/)与[数据录入](https://ant.design/docs/spec/data-entry-cn/)，参数默认阅读，源码和对照按需切换；编辑和预览共享草稿，取消恢复已保存值，保存成功后才退出编辑。
- 保存失败保留草稿并持续显示错误；空白校验定位编辑器。未保存保护覆盖步骤、返回与全局导航，保存和启动等待期间禁止重复提交。
- 说明参数更新使正文失效的具体时机，生成失败继续保留旧参数阅读；启动请求成功只反馈已启动，不冒充任务完成。成功过程默认折叠，阶段估算沿用统一组件。
- 复用分析页的 Markdown 阅读/编辑/表格主题，不另起视觉体系；窄内容区上下对照并内部滚动，全屏预览标明草稿，关闭恢复来源焦点。


### 正文及剩余业务共同规范

- 正文采用导航与阅读两区；窄区切换目录与正文，减少重复说明，任务进度与浏览步骤分开。阅读、源码和对照共享同一草稿，长内容在工作区内滚动。
- 空闲不摆放 0% 装饰进度；确定数值复用统一进度摘要，未知数值显示等待反馈。失败返回不得显示成功/100%，业务结果数量不可冒充任务完成。
- 保存/生成/审校配置请求期间锁定相关字段及关闭；失败就地持续提示并保留草稿。读取失败提供局部重试，区别于空列表与无成果。
- 项目集合默认每页 20 条；单页不显示分页，筛选变化回到首屏。新建完成后的初始化失败重试应复用已创建记录。
- 深色标题、字段、空态及表头使用语义主题变量；低频操作菜单支持键盘退出与回焦。正文保存成功后更新已保存权威内容，再退出编辑。


### 复杂资料与表格的反馈规则

- 导入预览与导出应保留表格层级与单元格段落，不把两段内容无分隔拼接；资料阅读器表格采用主题边框和 8×12px 单元格间距，正文 14/22，内容左对齐、顶部对齐。
- 不通过开启不可信 raw HTML 来恢复合并单元格；仅将表格的文本、换行和受限合并属性转换为安全结构，保留代码块原文。
- 整批导入失败要说明没有导入新资料、原资料/成果保留，并提供可执行的错误处理建议；无文字层 PDF 区分于普通读取失败。
- 图片必须从其实际业务工作区读取，预览和导出共用解析规则；保持现有 URL 可用，不向 Renderer 暴露任意项目目录。


## 复合输入控件的样式边界

- 输入框、选择器、日期和数字控件由外壳负责唯一背景和边框，内部输入层保持组件默认透明背景，不形成灰色胶囊或遮挡已选文本。
- 原生表单的背景、聚焦、自动填充与尺寸规则排除 Ant 控件输入节点，避免覆盖错误、禁用、搜索及多选状态。
- 列表输入即筛选时使用共享 EnterpriseSearchInput，前置搜索图标、后置清除；不附加无额外作用的搜索提交按钮。保留原筛选和分页逻辑，清除后返回输入框。


## 列表分页与返回

- 筛选、排序、翻页后结果从顶部显示；筛选保留输入焦点，分页键盘操作后焦点交回结果区域。详情返回保留查询、页码、排序、滚动和来源条目。
- 删除数据导致末页消失时同步实际页码，避免新增/恢复数据后跳回旧页；操作列在窄列表右侧固定，横向滚动由表格内部承担。
- 共享控件用稳定业务类名承载布局，不依赖被替换组件的旧内部类名。


## 菜单进入弹窗的焦点衔接

- 行操作菜单支持方向键展开、自动进入菜单项、Escape关闭并回到来源按钮。
- 菜单打开确认或重命名弹窗前，阻止原按键/点击默认动作，先聚焦稳定的来源按钮，再触发业务回调；弹窗记录这个来源，避免恢复到已隐藏的菜单项，避免原Enter延续激活弹窗按钮。


## 删除后的结果与焦点

- 取消删除返回原操作按钮；成功删除导致来源消失时，焦点转到当前可见列表的下一项或上一项，避免落到页面主体。
- 筛选下无可见相邻项时回搜索框并保留条件；没有搜索框且列表已空时回新建入口。
- 执行中禁止重复提交和关闭；失败保留原条目与持久错误，允许明确重试。错误与危险按钮在暗色表面保持可读文字对比。


## 同类项目索引统一

项目索引复用 ProjectListHeader、ProjectListToolbar、ProjectListTable、ProjectListActions；统一页头、字阶、搜索尺寸、时间格式和进入/更多操作，业务字段按模块需要提供。资料编辑、历史记录与正文工作区按任务保留，不因统一索引而强制改为表格。

排序使用图标、交互与 aria-sort 状态表达；Table 的 bodySortBg 与普通正文底色一致，headerSortActiveBg 与普通表头底色一致，避免整列灰色高亮。窄屏由表格内部滚动、右侧固定操作列承担，不扩张页面。
