# 可研正文编号与编辑验收

2026-10-30，design。

正文阅读区标题补充outlineEntries产生的展示编号，与目录树一致，数据关联仍使用原节点ID。可研全文预览/导出结构和存储数据未改。

使用实际ContentPanel、AppProviders、产品CSS与隔离桥接数据。目录叶子ID为fr-node-1/2，两节正文不同；contentSections中特意放旧正文缓存，确认阅读以outlineData内容为准。第一节长正文60段。

实际交互：编辑第一节，点击第二节触发未保存确认，取消保留草稿。第一次保存模拟reject，错误提示显示且编辑状态保留；第二次成功，切换第二节仍为第二节独立正文，切回第一节为新稿。保存后聚焦编辑入口。此为Renderer模拟，不是实际磁盘持久化验证；没有真实AI调用或用户数据变更。
