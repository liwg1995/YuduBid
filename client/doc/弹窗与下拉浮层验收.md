# 弹窗与下拉浮层验收

日期：2026-10-28，分支：design。

依据 Ant Design 的一致性、清晰反馈及对话框/浮层交互原则，沿用仓库 CSS、Radix 和主题变量，不增加依赖。

## 修复

- 共用 AppDialog 长正文恢复内部滚动，底部操作区保持可见。原样本可视高度678px、内容1549px且禁止滚动，按钮底边1570px，超过720px窗口；修复后按钮底边699px。
- 共用确认弹窗的长说明独立滚动并可键盘聚焦，初始取消焦点不会跳过标题。保留队列、危险操作与名称输入校验。
- 项目协作的项目类型/分组选择改用 Radix Popover Portal，避免祖先滚动容器裁切；支持窗口避让、搜索、新增、选择及焦点返回。浮层采用主题变量、14/22字阶及32px控件。
- 窄窗口验收发现现代主题通用 dialog 规则会覆盖 Popover 高度；排除该菜单，保留 Radix 的可用高度。菜单设置合理最小宽度，避免触发器较窄时选项逐字换行。

## 验证与边界

- 真实共享组件＋隔离 React 状态，classic/aurora/dark/modern × 1040×850、420×560，共8组合检查长弹窗、确认说明、菜单边界。窄窗口现代菜单的二次修复后边界为left168/right408/top198/bottom518，窗口420×560，可用最大高度350px。
- 项目弹窗内菜单可点击且显示在对话框上层；搜索选择第14项、自定义类型Enter确认、关闭后触发器焦点返回通过。
- 长确认初始取消焦点、Escape关闭；名称纯空白禁用确认、有效名称Enter提交通过。模拟任务执行时Escape不关闭且操作禁用，结束后恢复。
- 组件验收不访问真实项目、不调用模型或导出；不代表八模块所有业务链路完成。原生Electron窗口视觉回归及真实业务生成/导出仍须另行验证。
