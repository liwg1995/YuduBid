# 软件著作权模块发布候选版验收报告 0.8.0

## 验收结论

当前版本结论为“有条件通过”，可以进入内部发布候选版试用，不建议在完成真实 Windows 环境验收和代码签名方案前作为正式公开版本发布。

验收日期：2026年8月10日。

未签名产物复验日期：2026年8月11日。

## 已通过项目

- 软著代码扫描、草稿生成、历史版本、确认快照、正式导出和申报辅助端到端验证通过。
- 状态 Schema V4 迁移、异常任务恢复和未来版本拦截验证通过。
- TypeScript、Vite 生产构建、Electron Main、IPC 和 preload 检查通过。
- macOS arm64 目录包生成成功，打包应用实际启动无主进程日志错误。
- Windows x64 目录包、ZIP、NSIS 安装包和 blockmap 生成成功。
- macOS 与 Windows 的 `app.asar` 均包含软著模块核心文件，且包含对应平台的 `better-sqlite3` 原生模块。
- Windows 主程序经 PE 检查确认为 x64，ZIP 包含主程序和 `resources/app.asar`。
- macOS 不包含 Developer ID Authority 或 TeamIdentifier；Windows 主程序和 NSIS 安装包的 PE 证书目录为空。
- Windows 构建使用 `signExecutable: false`，macOS 构建使用 `identity: null`，本阶段未执行签名或公证。

## 安全依赖处理

已通过非破坏性升级和专项兼容验证，将生产依赖审计结果从11项漏洞降至0项。软著交付直接依赖 `adm-zip` 已升级至0.6系列，完整 ZIP 导出和产物读取验证通过。

- `pdfjs-dist` 已升级至6.2.108，`@napi-rs/canvas` 已升级至1.0.5；真实 PDF 转 Markdown 专项验证通过。
- 项目图片尺寸读取已替换为受控解析器，只接受 PNG、JPEG 和 GIF，明确拒绝 ICNS、JXL、HEIF/AVIF 及超限图片。
- PptxGenJS 中未使用的 `image-size` 传递依赖已替换为本地失败关闭包，带图片 PPTX 导出验证通过。
- `npm audit --omit=dev` 检查为0项漏洞。

后续依赖升级仍不得直接执行 `npm audit fix --force`，必须先审计调用方式并运行 `npm run verify:document-security`。
