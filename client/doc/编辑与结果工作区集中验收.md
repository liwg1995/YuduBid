# 编辑与结果工作区集中验收

2026-10-29，design分支。

## 改造

- 共用MarkdownEditor的异步插图回调改为读取最新value、disabled、onChange，防止等待选图时更换/修改稿件后覆盖新内容，或开始任务后旧回调仍可插入。保留当前选择与滚动位置，不新增业务存储。
- 编辑器增加Ctrl/Meta+B、Ctrl/Meta+I快捷键，忽略输入法组合及Alt/Shift组合；工具按钮提供aria-keyshortcuts，工具组具有group语义。共用编辑器表面、工具栏、禁用表面改为主题变量，补齐focus-visible。保持各页面的布局和高度约束。
- WorkspaceViewControl点击已选项不重复触发变更，保留按钮互斥状态及原逐项disabled条件。
- 论文结果区明确命名为工作稿预览/编辑与预览，预览和证据核对读取当前draft；清空工作稿后不回退显示旧结果。空稿不允许复制/导出，导出running禁用再次导出。保存时冻结编辑器。未修改Main、导出内容构建或持久化权威数据。
- 公文草稿保存期间禁用编辑器，saveDraft增加执行检查；课题工作稿保存/生成期间禁用编辑器。软著已有draftSaving禁用，项目协作已有运行禁用，审查后保留，本轮未改其相应代码。

## 实际验证

1. 实际MarkdownEditor隔离React状态：Meta+A选中“测试正文”，Meta+B得到**测试正文**，随后Meta+I得到***测试正文***。Mac平台使用Meta+A选择；首次用Control+A未选中文本，不计为选区快捷键通过。Windows实际键盘未验证。
2. 打开模拟图片选择后更换为新稿件，再完成选择，保留新工作稿及插图标记；切换disabled后再调用旧回调，内容完全不变。没有访问图片库或用户素材。
3. 实际ThesisTutorResultWorkspace：保存时编辑器禁用；导出running时按钮禁用；清空draft但保留旧result样本，旧结果不可见且导出禁用。当前稿件重新输入后预览同步。
4. 四主题×1040×850/420×700×三视图，共24组合无页面横向溢出。初次验证发现暗黑预览仍白底，补充共享/页面主题样式后重新24组验证，暗黑编辑与预览均为rgb(21,29,45)。
5. 1440×900现代对照视图，编辑区与预览各宽668px、高522px，顶底一致，间距12px。最终截图使用研究工作稿样本，无真实业务资料。
