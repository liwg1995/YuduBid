# 售前任务互斥、保稿与反馈验收

日期：2026-11-01；分支 design，保持累计工作未提交。

## 查明并修复

- 五类生成期间原先只禁用本阶段生成按钮，输入、保存和其他阶段生成仍可操作。本批增加工作区忙状态和生成入口同步锁：项目/材料/五阶段参数及保存、生成、Agent 执行入口统一禁用，仍允许切换阶段查看成果。
- `applyState` 原先在保存、生成和失败后刷新时无条件覆盖六组输入。现在同项目中保留相对上次读取状态有修改的本地输入；新项目或未修改字段正常同步服务快照。失败和成功均不冲掉其他阶段未保存的输入。
- 失败反馈原先在 finally 的 1200ms 定时器后删除，重新进入也只展示 running 任务。现在保留终态摘要，恢复页面时能展示服务保存的失败/成功结果；再次生成替换当前阶段反馈。
- 删除按时间递增的客户端估算进度。无真实百分比时显示阶段与不定进度；失败只保留原因/状态，成功只保留结果，不再展示整条进度和百分比。
- 清理 `.presales-task-card div/i/b` 旧样式，避免污染共享进度组件；终态卡片约 68px。共享 WorkspaceFormSection 新增可选 disabled，三类售前表单沿用语义 fieldset 禁用。
- 失败调试日志记录项目、阶段与错误，不记录模型输入正文。

依据：[Ant Design 反馈规范](https://ant-design.antgroup.com/docs/spec/feedback-cn)，提供阶段反馈，错误说明保留在相关区域并避免过度打扰。

## 实际 Renderer 验证

采用实际 PresalesWorkbenchPage、现有主入口样式及壳层选择器；状态由生产服务生成的合成初始数据提供，bridge 为可控制成功/失败的隔离实现，不调用模型。

五类任务 × 运行/失败/成功 × 四外观（启象、经典、柔光、暗黑）× 1280/800px，共 120 组：无 body 滚动或横向溢出，运行态可见参数全部禁用；终态无进度条，卡片高度 68px。

五阶段逐一执行：填写本阶段输入、另存一份未提交的项目背景 → 开始生成并确认锁定 → 模拟失败 → 输入/旧成果保留且解锁 → 重试成功 → 新成果显示、本阶段输入和项目背景仍保留。另验证运行分析时切至调研不能编辑或启动另一任务。

最终取消估算进度后复核分析运行/失败/成功：运行 `<progress>` 无 value，显示正在生成客户分析；失败无百分比，重试成功正常。重新加载有失败任务的样本能看到常驻错误摘要。
