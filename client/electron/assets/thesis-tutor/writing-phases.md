## 阶段⓪：启动诊断

### 三步诊断

1. **问学位**：本科/硕士/博士？学术学位还是专业学位？
2. **问专业+语种**：具体什么专业？哪个方向？中文还是英文论文？
3. **问状态**：🔴完全没方向 / 🟡有方向没定题 / 🟢题目已定 / 🔵正在写卡住了 / 🟣快写完需检查

### 学位差异对照表

| 维度 | 本科 | 硕士（学术型） | 硕士（专业学位）| 博士 |
|------|------|------|------|------|
| 正文字数 | 8k-15k | 2万-4万 | 2万-3.5万 | 8万-15万 |
| 创新要求 | 方法正确即可，不强求创新 | 应用创新或方法创新 | 实践价值>理论创新 | 必须理论创新，填补 gap |
| 方法复杂度 | 问卷/简单案例/文献分析 | 中阶统计/多案例/混合方法 | 案例/问卷/政策分析 | 高级方法/自主设计 |
| 参考文献量 | 15-30 篇 | 30-50 篇 | 25-40 篇 | 80-150 篇 |
| 时间估算(全职) | 8-12 周 | 16-24 周 | 12-20 周 | 1-3 年 |
| 查重标准(参考) | ≤30% | ≤15% | ≤15% | ≤10% |
| 答辩时间 | 5-8 min | 10-15 min | 10-15 min | 20-30 min |
| 是否需发表 | 否 | 通常否 | 通常否 | 是（1-2 篇核心期刊）|

**诊断简报**需根据学位差异输出不同的时间估算和成果预期。例：

```
本科诊断："不要求理论创新，重点在于方法正确、逻辑完整。最晚开题后 8 周出初稿。"
硕士诊断："需要一定创新（应用或方法层面）。数据收集是关键瓶颈，预留 16 周。"
博士诊断："必须有理论创新，填补文献中明确 gap。创新点要能经受答辩质疑。"
```

### 英文论文诊断

若用户回答语种为英语，自动切换以下配置：
- 引用格式：APA 7th（社科）/ MLA 9th（人文）/ IEEE（理工）
- 大纲结构：Abstract → Introduction → Literature Review → Methodology → Results → Discussion → Conclusion
- 字数参考：本 5k-8k words / 硕 15k-25k words / 博 60k-100k words
- 评审标准：contribution / rigor / clarity / originality

### 诊断简报模板

```
## 诊断简报
- 学位类型：{X} / 学科：{Y} / 语种：{中文/英文}
- 当前阶段：{Z} / 卡点：{W}
- 时间估算：约 {X} 周
- 建议路径：阶段N → 阶段N+1 → ...
- {学位差异提示：如"本科不要求理论创新，方法正确、逻辑完整即可"}

准备好了？我们从阶段N开始。
```

**规范**：不问已知信息、不问开放问题、用户说"你看着办"直接推进。

## 阶段①：选题与开题

### 步骤 1.1：选题生成

基于专业+方向生成 3-5 个候选题目，每个附带难度/创新性/资料充足度评估。

**评估维度**：
- 数据可获得性
- 研究周期匹配度
- 创新空间
- 文献支持度

**MPA/专业学位避坑**：
- 优先：有实践场景、可获一手数据、有政策/管理针对性
- 避免：纯理论推演、无实践落点、数据无法获取

### 步骤 1.2：开题报告结构

1. **研究背景与意义** — 从具体现象切入，不要"随着XXX发展"
2. **国内外研究现状** — 按观点/流派分类，不要逐条罗列
3. **研究目标与内容** — 目标具体可衡量
4. **研究方法与技术路线** — 方法服务于研究问题
5. **预期成果与创新点** — 新在角度/方法/数据
6. **研究计划与时间安排** — 倒推法，预留缓冲

## 阶段②：文献检索与综述

> 🟠 扩展模块：文献检索需外部工具（CNKI/OpenAlex/Google Scholar 等）。本技能生成检索策略和关键词，用户自行检索后提供文献资料，AI 负责分析、分类和综述撰写。

### 步骤 2.1：关键词与检索策略

分析研究主题，生成中英文关键词（各 5-8 个）和各数据库检索式。

### 步骤 2.2：用户提供文献后的处理

1. 提取标题、作者、年份、期刊、核心观点
2. 去重：DOI 匹配 + 标题相似度 > 0.85
3. 筛选：近 10 年优先、核心期刊优先、被引量排序
4. 目标：中英文各 15-25 篇，总计 30-50 篇

#### 文献批量处理指引（≥20篇时启用）

当用户一次性提供20篇以上文献时，建议：

1. **分批次提供**：每次5-10篇，标注"批次1/4"，AI处理完一批再给下一批，避免上下文溢出。
2. **使用摘要表格模板**：如文献为PDF全文，用户可填写以下表格关键字段，AI据此提取核心观点：

| 字段 | 说明 | 示例 |
|------|------|------|
| 作者(年份) | 标准引用 | 张三(2022) |
| 研究问题 | 作者想回答什么 | 数字政府如何影响基层行政效率 |
| 理论框架 | 用了什么理论 | TOE框架、制度理论 |
| 方法 | 样本/数据/分析方法 | 问卷调查N=312，结构方程模型 |
| 关键发现 | 1-2句核心结论 | 技术准备度正向影响，组织支持调节 |
| 创新/局限 | 可选 | 首次结合X与Y；横截面数据 |
| 归属章节 | 建议放哪 | 2.1概念界定 或 4.2讨论 |

> 用户只需提供纯文本表格或Excel粘贴，AI即可批量分析。如用户无法填写，则仍按原文提取，但建议分批。

#### 文献管理工具推荐

- **Zotero**（免费）：安装后添加"GB/T 7714-2015（numeric，中文版）"样式（可自行微调以适配2025版），选中文献即可一键生成标准引用列表。
- **CNKI E-Study**：直接导出GB/T 7714格式。
- **Mendeley/EndNote**：需下载对应的GB/T 7714样式文件。

> 建议用户在检索阶段即使用工具收集文献，避免手动整理错误。

### 步骤 2.3：深度文献分析

每篇文献分析：研究问题、理论框架、方法、关键发现、创新/局限、与其他文献关系、争议点。

### 步骤 2.4：综述四步迭代合成

**Step 1 — Outline**：基于主题聚类，生成综述大纲（3-5 个主题板块）

**Step 2 — Writing**（3000-5000 字）：主题式合成而非逐篇罗列，对比不同研究、标注争议

**Step 3 — Review**：6 维审查（准确性/逻辑性/引用/批判性/语言/创新性），0-100 评分

**Step 4 — Final**：修订后添加摘要（200-300 字）+ 关键词（5-8 个）

### 步骤 2.5：引用格式化

输出 GB/T 7714-2025 标准格式引用列表。

## 阶段③：研究设计与方法

### 方法匹配诊断

| 选题特征 | 推荐方法 |
|---------|---------|
| 测量变量关系 | 量化研究（问卷法）|
| 理解深层原因 | 质性研究（访谈/案例）|
| 既有变量又有理解 | 混合方法 |
| MPA 政策分析 | 政策文本分析/案例比较 |

### 量化研究五步

1. 研究设计：变量设计 + 假设清单
2. 预测试：30-50 份有效问卷 + 信效度
3. 正式发放：样本量估算 + 回收策略
4. 数据分析：描述性统计→信效度→相关→回归→中介/调节
5. 结果呈现：统计表格 + 讨论

**SPSS 核心检查**：信度 α ≥ 0.7，效度 KMO ≥ 0.7，Bartlett p < .05

#### 数据来源标注规范

- **一手问卷数据**：在首次出现时注明"本研究于2025年X月通过线上+线下方式对XX群体发放问卷，回收有效问卷N份，有效回收率X%。"
- **二手数据**：注明下载日期和数据版本，如"数据来源于国家统计局《中国统计年鉴2024》的'城镇居民收入与支出'表，下载于2025年1月15日。"
- **访谈数据**："受访者编码为A01-A15，访谈时间为2025年3月-4月，平均时长45分钟。"
- **案例材料**："案例企业XX的年报、官网公开信息，以及作者于2024年7月进行的实地调研笔记。"

### 高级方法速查

以下方法需学生有一定统计基础。只提供核心步骤和常见错误，不替代统计教材。

#### 结构方程模型 (SEM)

**适用场景**：多变量因果路径分析，含潜变量（如"满意度""忠诚度"等不可直接观测的变量）。

**核心步骤**：
1. 理论模型构建（基于文献绘制路径图）
2. 验证性因子分析(CFA)：检验测量模型（标准化载荷 > 0.5，AVE > 0.5，CR > 0.7）
3. 结构模型检验：路径系数显著性（p < .05）+ 拟合指数达标
4. 中介效应：Bootstrap 5000 次，看间接效应置信区间是否跨 0

**拟合指数阈值**：χ²/df < 3，CFI > 0.90，TLI > 0.90，RMSEA < 0.08，SRMR < 0.08

**常见错误**：
- ❌ 样本量不足（SEM 至少 200，最好 300+）
- ❌ 不做 CFA 直接跑结构模型
- ❌ 用 HLM 软件的标准修改指数盲目调模型（须有理论依据）

#### 双重差分法 (DID)

**适用场景**：政策效果评估，有实验组和对照组的前后数据。

**核心步骤**：
1. 确认平行趋势假设（政策前两组趋势一致）——可画时间趋势图直观检验
2. 模型：Y = β₀ + β₁·Treat + β₂·Post + β₃·(Treat×Post) + ε，β₃ 即政策效应
3. 稳健性：安慰剂检验（假设政策提前 1 期，看 β₃ 是否仍显著）
4. 异质性分析：分地区/分群体看效应差异

**常见错误**：
- ❌ 不检验平行趋势直接跑 DID
- ❌ 样本只有一期（DID 至少需要两期数据）
- ❌ 忽略其它同期政策干扰

#### 回归不连续设计 (RDD)

**适用场景**：有明确断点（如分数线、年龄阈值），断点两侧个体可比较。

**常见错误**：❌ 断点附近样本量不足（至少 50+）、❌ 未做密度检验（检验是否有人操控断点）

### 质性研究

- 半结构化访谈：本科 10-15 人/硕士 15-30 人
- 案例研究：1-4 个案例
- 数据分析：主题分析法六步（Braun & Clarke, 2006）
- 质量保障：可信性/可转移性/可靠性/可确认性

#### 扎根理论编码

**适用场景**：从原始数据中归纳理论（而非验证已有理论），适用于社会学/管理学/教育学。

**三级编码**：
1. **开放式编码**：逐行逐句贴标签 → 提炼概念 → 归纳初始范畴（30-50 个）
2. **主轴编码**：建立范畴间逻辑关系（因果/并列/包含/时间），归纳为 5-8 个主范畴
3. **选择性编码**：确定核心范畴，构建故事线，形成理论框架

**编码工具**：NVivo、MAXQDA 或手动 Excel

**常见错误**：
- ❌ 编码前预设理论框架（扎根理论的要义是"从数据中生成理论"）
- ❌ 编码后不画范畴关系图
- ❌ 三级编码混淆（主轴不是重新编码，是建关系）
- ❌ 不写编码备忘录（编码过程中的思考记录，是最终理论的重要支撑）

**理论饱和度检验**：新增 3-5 份访谈不再产生新范畴，证明已饱和。

## 阶段④：逐章写作

### 🔑 文献驱动写作四步法

```
① 索要文献 → ② 提取确认 → ③ 撰写初稿 → ④ 交付确认
```

### 第一步：索要文献

写任何章节正文前，必须先向用户索要文献。话术：

> 准备写【{章节名}】了。请把相关的参考文献资料给我（标题+作者+摘要即可，PDF 也可以）。有条就给条，没条扔文件我来提取。

### 第二步：提取与确认

收到文献后整理分类并确认：

> 收到{N}条文献。我整理的对应关系：📄 张三(2022)→1.1 研究背景+2.1 概念界定；📄 Li(2021)→1.3 研究现状+2.3 综述...确认无误我开始写？

### 第三步：撰写初稿

- 每条论述标注引用来源：[1]张三(2022)
- 不编造引用，不添加用户未提供的文献
- 缺材料处留白：[此处需补充 XX 类型文献]
- 学术化表达，避免 AI 套话

### 第四步：交付确认

交付时附带引用来源对照表，每条引用注明对应哪条用户提供的文献。

### 大纲模板（带文献需求标注）

```markdown
# {论文标题}

## 第一章 绪论
### 1.1 研究背景 📎政策文件/行业报告/新闻数据(3-5条)
### 1.2 研究目的与意义 📎"研究不足/未来展望"段落(3-5条)
### 1.3 国内外研究现状 📎中文15-20篇+英文10-15篇摘要

## 第二章 理论基础与文献综述
### 2.1 核心概念界定 📎权威定义出处(3-5条)
### 2.2 理论基础 📎经典理论原文/相关文献(5-10条)
### 2.3 文献综述与述评 📎核心文献摘要(15-30条)

## 第三章 研究设计
### 3.2 研究方法 📎方法论参考文献(3-5条)

## 第四章 研究结果与分析
### 4.x 📎用户数据+对比讨论文献

## 第五章 结论与建议
### 5.2 政策建议/实践启示 📎政策文件/实践报告
```

### 批注修改模式

- 📐 结构问题 → 🔍 论证问题 → ✍️ 表述问题 → ➕ 补充建议 → 📎 还需文献

导师反馈解读：论证不足/逻辑不清/结构问题/深度不够/格式问题/方法质疑 → 给方案 → 确认需补充文献 → 修改标注改动。

### 材料加工

文献 PDF → 提取文字 → 归纳观点 → 匹配章节；政策文件 → 提炼要点 → 背景/建议用；问卷数据 → 统计方法提示；访谈 → 编码主题；案例 → 结构化描述。

### 引用管理

正文：[1] [1,3-5] 数字上标；参考文献：GB/T 7714-2025；每章更新引用-文献对照表。
