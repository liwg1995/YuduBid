# 文献综述专项指南

## 文献综述的目的

### 不是
- 文献罗列（谁做了什么）
- 读书摘要（逐篇介绍）
- 堆砌引用（显示读了很多）

### 而是
- 研究地图（领域全貌）
- 对话参与（与文献对话）
- Gap识别（找到切入点）
- 理论框架（支撑你的研究）
- 方法论借鉴（学习研究方法）

## 文献类型

### 按内容
- **理论文献**：概念、模型、框架
- **实证文献**：研究发现、数据集
- **方法文献**：研究方法、技术
- **综述文献**：元分析、系统综述
- **政策文献**：报告、白皮书

### 按重要性
- **奠基性（Foundational）**：领域开创者，必引
- **里程碑（Milestone）**：重要突破，常引
- **最新进展（State-of-the-art）**：近3-5年，展示前沿
- **直接相关（Directly relevant）**：与你的研究最相关
- **方法论（Methodological）**：方法借鉴

## 文献检索策略

### 数据库选择
- **中文**：CNKI、万方、维普、读秀
- **英文**：
  - 综合：Web of Science、Scopus、Google Scholar
  - 社科：SSCI、PsycINFO、ERIC
  - 医学：PubMed、Cochrane
  - 工程：IEEE Xplore、ACM Digital Library
  - 经济：EconLit、NBER
  - 法律：HeinOnline、Westlaw

### 检索技巧
- **布尔逻辑**：AND（交集）、OR（并集）、NOT（排除）
- **截词**：*（通配）、?（单字符）
- **短语**："exact phrase"
- **字段**：title:、author:、journal:
- **引文追踪**：前向（被引）、后向（引用）

### 检索策略构建
1. **分解研究问题**：PICO（Population, Intervention, Comparison, Outcome）
2. **提取关键词**：同义词、近义词、上下位词
3. **构建检索式**：(A OR B OR C) AND (D OR E) AND F
4. **调整优化**：根据初步结果调整

## 文献管理

### 工具
- **Zotero**：免费、开源、插件丰富
- **EndNote**：功能全面、与Word集成好
- **Mendeley**：社交功能、PDF管理
- **NoteExpress**：中文支持好
- **Citavi**：知识管理强

### 管理策略
- **分类**：按主题、方法、理论
- **标签**：多维度标记
- **笔记**：阅读时记录（摘要、评价、关联）
- **同步**：云端备份

## 阅读策略

### 分层阅读
1. **标题+摘要**：判断相关性（2分钟）
2. **引言+结论**：了解核心贡献（5分钟）
3. **全文精读**：关键文献（30-60分钟）
4. **批判性阅读**：质疑、评估、联系

### 阅读笔记模板
```
- 基本信息：作者、年份、期刊、题目
- 研究问题：核心问题是什么？
- 理论框架：用了什么理论？
- 研究方法：怎么做的？
- 主要发现：结论是什么？
- 评价：优点、缺点、局限
- 关联：与我的研究的关系
- 引用价值：是否值得引用？
```

## 综述结构

### 时序结构（Chronological）
- 按时间发展
- 展示演变脉络
- 适合：历史研究、技术发展

### 主题结构（Thematic）
- 按主题/话题组织
- 最常见
- 适合：大多数研究

### 方法论结构（Methodological）
- 按研究方法组织
- 比较不同方法
- 适合：方法论文

### 理论结构（Theoretical）
- 按理论流派组织
- 比较不同理论
- 适合：理论论文

### 问题结构（Problem-Cause-Solution）
- 问题→原因→解决方案
- 适合：应用研究

## 写作技巧

### 段落结构（推荐）
```
主题句：这一节讨论...
文献呈现：A(2010)发现...；B(2012)指出...
对比分析：然而，C(2015)质疑...
评价总结：这些研究表明...
过渡：但仍有以下不足...
```

### 引用方式
- **信息突出**：研究发现...（Smith, 2010）
- **作者突出**：Smith（2010）发现...
- **多作者**：Smith and Jones（2012）/ Smith et al.（2013）
- **多文献**：Several studies（Smith, 2010; Jones, 2012; Lee, 2015）

### 批判性写作
- 不是"A说...B说...C说..."
- 而是"A和B都支持X观点，但C基于Y理由质疑，本文认同C，因为..."
- 使用连接词：
  - 一致：Similarly, In line with, Consistent with
  - 对比：However, In contrast, Conversely
  - 递进：Moreover, Furthermore, Additionally
  - 总结：In summary, Taken together, Overall

### 常见句型
- **介绍研究**："In a seminal study, Smith (2010) demonstrated that..."
- **指出不足**："However, this study was limited by..."
- **建立联系**："Building on this work, Jones (2012) extended..."
- **识别Gap**："Despite these advances, little is known about..."
- **定位研究**："The present study addresses this gap by..."

## 避免抄袭

### 正确做法
- **直接引用**：加引号+页码+出处
- **改写（Paraphrase）**：用自己的话+出处
- **总结（Summarize）**：概括大意+出处
- **综合（Synthesize）**：多篇整合+多处出处

### 改写技巧
- 改变句子结构（主动被动）
- 替换同义词（保持学术准确）
- 改变视角（从作者角度）
- 加入自己的解释

### 错误示例
- 只改几个词（仍算抄袭）
- 改变语序但保留原结构
- 遗漏引用

## 质量检查

### 完整性
- [ ] 涵盖奠基性文献
- [ ] 包含最新进展（近3-5年）
- [ ] 包含直接相关文献
- [ ] 包含方法论文献
- [ ] 中英文文献平衡（如适用）

### 批判性
- [ ] 不是简单罗列
- [ ] 有对比分析
- [ ] 有评价判断
- [ ] 识别了Gap
- [ ] 建立了理论框架

### 逻辑性
- [ ] 结构清晰
- [ ] 过渡自然
- [ ] 论证连贯
- [ ] 与全文衔接

## 常见问题

**Q：要读多少篇文献？**
A：硕士30-50篇，博士100-200篇，本科15-30篇。重质不重量。

**Q：综述写多长？**
A：本科3000-5000字，硕士5000-10000字，博士10000-20000字。占全文10-20%。

**Q：引用多少篇？**
A：本科15-30篇，硕士30-60篇，博士60-120篇。看学科惯例。

**Q：怎么找Gap？**
A：1）方法局限；2）样本局限；3）情境空白；4）矛盾发现；5）未探索变量。

**Q：文献综述和绪论的区别？**
A：绪论包括研究背景、问题提出、研究意义；文献综述是其中一部分，专门梳理文献。

# 查重与 AI 检测指南

## 查重系统原理

### 文本匹配算法
- **连续字符匹配**：13字连续相同即标红（知网）
- **语义匹配**：同义改写仍可能识别（Turnitin）
- **跨语言匹配**：翻译后抄袭可检测
- **公式/代码**：部分系统不计入，部分计入

### 主要查重系统
| 系统 | 特点 | 适用 |
|------|------|------|
| 知网（CNKI） | 中文文献最全，高校主流 | 硕博论文 |
| 维普 | 期刊文献多，严格 | 本科/期刊 |
| 万方 | 医学文献强 | 医学领域 |
| Turnitin | 英文主流，国际通用 | 英文论文 |
| iThenticate | 期刊投稿，详细报告 | SCI/SSCI |
| PaperPass | 免费/低价，初查 | 初稿自查 |
| 大雅 | 学习通关联，免费 | 初查 |

## 查重报告解读

### 关键指标
- **总文字复制比**：全文重复率
- **去除引用复制比**：去掉标注引用后的重复率
- **去除本人文献**：去掉自己已发表文献
- **单篇最大重复**：重复最多的单篇来源
- **重复字数**：具体重复字数

### 颜色标记（知网）
- 红色：重度重复（>75%）
- 橙色：中度重复（50%-75%）
- 黄色：轻度重复（25%-50%）
- 绿色：低度重复（<25%）

### 学校要求（参考）
- 本科：通常 < 20%-30%
- 硕士：通常 < 10%-15%
- 博士：通常 < 5%-10%
- 期刊：通常 < 10%-20%（看期刊要求）

## 降重策略

### 合法策略
1. **同义替换**
   - 保持学术准确
   - 避免口语化
   - 例："重要"→"关键"/"核心"/"显著"

2. **句式重组**
   - 主动被动转换
   - 长短句变换
   - 语序调整（保持逻辑）

3. **图表化**
   - 文字描述转表格
   - 流程图替代文字
   - 数据可视化

4. **增删改写**
   - 增加自己的分析
   - 删除冗余引用
   - 用自己的话概括

5. **引用规范**
   - 直接引用标注（引号+出处）
   - 间接引用改写（仍需标注）
   - 控制引用比例

### 危险策略（不推荐）
- 翻译降重：中→英→日→中（语句不通）
- AI降重：可能被AI检测识别
- 图片替代：部分系统OCR识别
- 空格/特殊字符：系统已能识别
- 乱码插入：明显作弊

### 各学科注意事项
- **理工科**：公式描述、实验步骤可标准化，但需用自己的话
- **文科**：理论综述最易重复，需批判性改写
- **法学**：法条原文不计入，但需标注；案例概括用自己的话
- **医学**：病历描述、治疗方案可标准化
- **计算机**：代码片段部分系统不计入

## AI 检测

### 检测原理
- **困惑度（Perplexity）**：AI文本困惑度低
- **突发性（Burstiness）**：人类写作波动性大
- **统计特征**：词频分布、句长分布
- **水印检测**：部分AI生成器嵌入水印

### 主要检测工具
| 工具 | 特点 | 局限 |
|------|------|------|
| GPTZero | 免费，流行 | 误判率高 |
| Turnitin AI | 集成查重 | 英文为主 |
| 知网AIGC | 中文检测 | 新推出，标准不明 |
| 维普AIGC | 中文检测 | 同上 |
| Originality.ai | 专业，付费 | 英文为主 |
| ZeroGPT | 免费 | 误判 |

### 学校政策趋势
- 2024年起多校要求检测AI率
- 标准不统一（0%-30%都有）
- 检测工具准确性存争议
- 申诉机制不完善

### 降低AI检测风险（合规方式）
1. **增加个人声音**
   - 加入研究经历、反思
   - 使用第一人称（如适用）
   - 加入具体细节（时间、地点、感受）

2. **混合写作**
   - 自己写初稿，AI辅助润色
   - 分段写作，不要整篇AI生成
   - 关键论点自己组织

3. **深度编辑**
   - 改写AI生成的平淡表达
   - 增加过渡句、连接词
   - 调整段落结构

4. **引用真实文献**
   - AI可能编造引用
   - 核实每条引用
   - 加入最新文献

5. **使用检测工具自查**
   - 提交前用多个工具检测
   - 标记高风险段落
   - 重点改写

## 学术诚信

### 抄袭类型
- **直接抄袭**：复制粘贴，不标注
- **马赛克抄袭**：拼接多来源，不标注
- **改写抄袭**：改写但观点/结构照搬
- **自我抄袭**：重复发表自己已发表内容
- **数据造假**：编造、篡改数据
- **代写**：请人/AI代写

### 后果
- 论文不通过
- 学位撤销（已授予）
- 学术处分（警告、记过、开除）
- 学术声誉损失
- 法律责任（严重情况）

### 正确做法
- 所有引用标注来源
- 直接引用用引号
- 间接引用用自己的话+标注
- 参考文献完整列出
- 使用引文管理工具
- 保留写作过程记录

## 常见问题

**Q：引用自己已发表的论文算重复吗？**
A：算，但多数学校允许一定比例（需标注"本人论文"）。

**Q：参考文献列表算重复吗？**
A：通常不计入，但格式要正确。

**Q：附录算重复吗？**
A：通常计入全文，但部分学校附录单独计算。

**Q：使用AI辅助写作算学术不端吗？**
A：看学校政策。多数允许辅助（润色、翻译），禁止代写（生成核心内容）。

**Q：查重率越低越好吗？**
A：不是。0%可能意味着没有文献支撑，合理引用是必要的。

**Q：不同查重系统结果差异大吗？**
A：大。数据库不同，算法不同。以学校指定系统为准。

- **MathType**：专业，收费
- **LaTeX**：最强大，学习曲线陡峭
- **AxMath**：国产，MathType替代

## 翻译与润色

### 翻译工具
- **DeepL**：质量最高（英译中）
- **Google Translate**：通用
- **CNKI翻译助手**：学术术语
- **有道翻译**：国产，够用

### 润色工具
- **Grammarly**：语法检查
  - 免费版基础
  - 付费版高级建议

- **QuillBot**：改写润色
  - 免费版有限制
  - 注意：可能触发AI检测

- **Writefull**：学术写作
  - 基于学术语料库
  - 适合：非母语者

## 查重与AI检测

### 查重
- **学校指定系统**：最准确（知网/维普/万方）
- **PaperPass**：初查，免费/低价
- **大雅**：学习通关联，免费
- **Turnitin**：英文，国际通用

### AI检测
- **GPTZero**：免费，流行
- **Turnitin AI**：集成查重
- **知网AIGC**：中文检测
- **ZeroGPT**：免费

## 协作与版本控制

### 版本控制
- **Git + GitHub**：代码/文本

  - 不适合：Word（二进制）

- **Word修订模式**：传统方式

  - 批注功能
  - 比较文档

### 云同步
- **OneDrive**：微软生态
- **百度网盘**：国内通用
- **坚果云**：同步盘
- **Dropbox**：国际通用

## 避坑指南

1. **不要用盗版软件**：学校通常提供正版
2. **不要过度依赖翻译**：学术写作需自己组织
3. **不要忽视备份**：云同步+本地备份
4. **不要临时学工具**：提前熟悉，避免 deadline 前手忙脚乱
5. **不要忽视格式**：排版也是学术规范的一部分
