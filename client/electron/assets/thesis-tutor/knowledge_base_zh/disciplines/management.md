# 管理学/工商管理论文写作指南

## 学科特点
- 强调理论框架、实证验证、管理启示
- 重视数据来源、变量测量、内生性处理
- 期刊论文为主（顶刊：AMJ/SMJ/JOM/OS/MS）
- 案例研究受欢迎（理论构建/检验）

## 研究类型

### 1. 案例研究
- **适用**：新现象探索、理论构建、复杂过程
- **类型**：
  - 单案例（极端/典型/纵向）
  - 多案例（复制/对比/互补）
- **设计要点**：
  - 案例选择（理论抽样，非随机）
  - 数据收集（访谈/档案/观察/多源）
  - 分析策略（模式匹配/解释构建/时序）
  - 信度保障（三角验证/成员检查/审计追踪）
- **报告规范**：
  - 背景描述丰富（情境化）
  - 证据链清晰（数据→图表→结论）
  - 与文献对话（证实/扩展/挑战）

### 2. 调查研究
- **适用**：大样本假设检验、变量关系
- **类型**：横截面/纵向/面板
- **设计要点**：
  - 抽样框架（目标总体可及）
  - 问卷设计（成熟量表+自编题项）
  - 数据收集（在线/纸质/混合）
  - 共同方法偏差（Harman单因子/程序控制）
- **分析方法**：
  - 结构方程模型（SEM）：AMOS/PLS/Mplus
  - 多层线性模型（HLM）：跨层数据
  - 潜增长模型（LGM）：纵向追踪

### 3. 实验研究
- **适用**：因果关系、行为机制
- **类型**：实验室/现场/准实验/自然实验
- **设计要点**：
  - 随机分配（真随机/配对随机）
  - 操纵检查（自变量是否有效操纵）
  - 因变量测量（客观/主观/行为）
  - 控制变量（混淆因素排除）
- **分析方法**：
  - ANOVA/ANCOVA：组间比较
  - 中介/调节：PROCESS宏
  - 多层次：HLM

### 4. 二手数据分析
- **适用**：宏观研究、面板数据、事件研究
- **数据来源**：
  - 上市公司：CSMAR、Wind、国泰安
  - 专利数据：国家知识产权局、Derwent
  - 招聘数据：智联招聘、前程无忧
  - 社交媒体：微博、知乎、脉脉（爬虫）
- **分析方法**：
  - 面板数据模型：固定效应/随机效应/GMM
  - DID/PSM：因果推断
  - 事件研究：CAR计算
  - 文本分析：词频、主题模型、情感分析

## 理论框架

### 常用理论
- **资源基础观（RBV）**：VRIN资源→竞争优势
- **制度理论**：规制/规范/认知制度压力
- **代理理论**：委托代理冲突→治理机制
- **利益相关者理论**：多主体平衡
- **动态能力**：感知/捕捉/重构
- **组织学习**：探索/利用、知识转化（SECI）
- **高阶理论**：高管特征→战略选择→组织结果
- **社会网络**：结构洞/中心性/嵌入性
- **信号理论**：信号发送→信号解读→结果
- **合法性理论**：实用/道德/认知合法性

### 理论使用建议
1. **不要堆砌理论**：1-2个核心理论足够
2. **明确理论视角**：解释什么、预测什么
3. **理论与假设对接**：每个假设有理论支撑
4. **理论对话**：结果与理论预期一致/矛盾/扩展

## 数据来源与测量

### 问卷设计
- **量表来源**：优先使用成熟量表（信效度已验证）
- **翻译回译**：英文量表→中文→回译→对比
- **题项数量**：每个构念3-7题（避免疲劳）
- **反向计分**：混入2-3题（防止默认反应）
- **预测试**：30-50人，CITC<0.4删除

### 常用数据库
- **CSMAR**：上市公司财务、治理、股权
- **Wind**：金融、宏观、行业
- **国泰安**：经济金融、区域经济
- **CEIC**：宏观经济、行业数据
- **世界银行**：跨国比较、发展指标
- **中国家庭追踪调查（CFPS）**：微观个体
- **中国健康与养老追踪调查（CHARLS）**：老龄化

### 变量测量
- **自变量**：明确操作化定义
- **因变量**：多维度测量（客观+主观）
- **中介变量**：机制解释
- **调节变量**：边界条件
- **控制变量**：排除替代解释

## 分析方法

### 结构方程模型（SEM）
- **CB-SEM（AMOS/Mplus）**：
  - 大样本（>200）
  - 验证性分析
  - 严格模型拟合（CFI>0.9, RMSEA<0.08, SRMR<0.08）
- **PLS-SEM（SmartPLS）**：
  - 小样本可接受
  - 探索性分析
  - 预测导向（PLSpredict）

### 多层线性模型（HLM）
- **适用**：嵌套数据（员工→团队→组织）
- **软件**：HLM、Mplus、R（lme4）
- **报告**：ICC(1)、ICC(2)、rwg、跨层效应

### 定性比较分析（QCA）
- **适用**：因果复杂性、多因素组合
- **类型**： crisp-set / fuzzy-set / mvQCA
- **软件**：fsQCA、R（QCA包）
- **报告**：真值表、一致性、覆盖度、中间解

### 内生性处理
- **来源**：遗漏变量、反向因果、测量误差、样本选择
- **方法**：
  - 工具变量（IV）：2SLS
  - 双重差分（DID）：政策冲击
  - 倾向得分匹配（PSM）：样本匹配
  - 断点回归（RDD）：阈值附近
  - Heckman模型：样本选择

## 论文结构模板

### 实证研究（定量）
```
1. 引言
   - 现实背景（管理现象）
   - 理论缺口（文献对话）
   - 研究问题
   - 理论贡献
   - 实践意义

2. 文献综述与假设
   - 核心构念定义
   - 主效应文献（A→B）
   - 中介机制（A→M→B）
   - 调节边界（W影响A→B）
   - 假设汇总表

3. 研究设计
   - 样本与程序
   - 变量测量（量表来源+信度）
   - 分析策略
   - 共同方法偏差控制

4. 结果
   - 描述性统计+相关矩阵
   - 测量模型（CFA/信效度）
   - 结构模型（路径系数+显著性）
   - 中介效应（Bootstrap）
   - 调节效应（交互项/简单斜率）
   - 稳健性检验（替代测量/子样本）

5. 讨论
   - 假设验证总结
   - 理论贡献（对话）
   - 管理启示（可操作）
   - 局限性（样本/方法/因果）
   - 未来研究（具体方向）
```

### 案例研究（定性）
```
1. 引言：现象→问题→方法→贡献
2. 文献综述：理论视角→缺口→框架
3. 方法：
   - 案例选择（理论抽样逻辑）
   - 数据收集（多源证据矩阵）
   - 数据分析（编码策略）
   - 信度保障（三角验证等）
4. 案例描述：背景→过程→关键事件
5. 跨案例分析：模式→命题→理论
6. 讨论：贡献→启示→局限→未来
```

## 常见错误
1. 理论框架薄弱（假设缺乏理论支撑）
2. 内生性忽视（因果推断不可靠）
3. 共同方法偏差（同源数据未处理）
4. 量表随意改编（破坏信效度）
5. 中介效应解释错误（完全中介≠中介）
6. 调节效应图错误（简单斜率方向）
7. 样本选择偏差（便利抽样推广）
8. 过度控制变量（控制中介/调节）
9. 结果选择性报告（只报显著结果）
10. 管理启示空洞（缺乏可操作性）
