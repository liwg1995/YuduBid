# 理学论文写作指南

## 学科特点
- 强调实验验证、数学推导、理论创新
- 重视数据精确性、可重复性、同行评审
- 会议论文与期刊论文并重
- 图表质量要求高（数据图、公式、实验装置图）

## 研究类型

### 1. 实验研究
- **适用**：物理、化学、生物实验
- **核心要素**：
  - 实验设计（变量控制、重复实验）
  - 数据采集（仪器精度、误差分析）
  - 结果分析（统计检验、不确定度）
- **论文结构**：目的→方法→实验→结果→分析

### 2. 理论研究
- **适用**：数学、理论物理、理论化学
- **核心要素**：
  - 问题提出（猜想、假设）
  - 理论推导（证明、计算）
  - 结果讨论（意义、应用）
- **论文结构**：问题→预备→主要结果→证明→讨论

### 3. 计算研究
- **适用**：计算物理、计算化学、生物信息学
- **核心要素**：
  - 模型建立（算法、数值方法）
  - 程序实现（代码、验证）
  - 结果分析（收敛性、精度）
- **论文结构**：问题→方法→实现→结果→讨论

## 学科细分

### 数学
- **纯数学**：代数、几何、分析、数论
- **应用数学**：概率统计、运筹学、计算数学
- **数学教育**：教学方法、课程设计

### 物理学
- **凝聚态物理**：材料、超导、半导体
- **粒子物理**：高能物理、核物理
- **光学**：激光、光纤、光电子
- **天体物理**：宇宙学、星系、黑洞

### 化学
- **有机化学**：合成、反应机理
- **无机化学**：配位化学、材料化学
- **分析化学**：仪器分析、光谱学
- **物理化学**：热力学、动力学

### 生物学
- **分子生物学**：基因、蛋白质
- **细胞生物学**：细胞信号、细胞周期
- **生态学**：种群、群落、生态系统
- **生物信息学**：序列分析、结构预测

## 论文结构模板

### 实验研究型
```
1. 引言（研究背景、问题、目的）
2. 实验部分（材料、方法、仪器）
3. 结果与讨论（数据、分析、比较）
4. 结论（发现、意义、展望）
```

### 理论研究型
```
1. 引言（问题背景、文献综述）
2. 预备知识（定义、引理）
3. 主要结果（定理、证明）
4. 讨论（应用、推广）
5. 结论（贡献、展望）
```

## 写作要点

### 实验描述
- 详细到可重复
- 包含所有参数
- 说明仪器型号
- 注明试剂来源

### 数据呈现
- 使用有效数字
- 报告误差范围
- 标注单位
- 图表清晰规范

### 公式排版
- 使用公式编辑器
- 统一符号体系
- 编号连续
- 解释每个符号

## 常见问题

1. **实验不充分**：重复次数少，缺乏对照
2. **数据处理不当**：统计方法错误，误差分析不足
3. **文献综述薄弱**：缺乏最新进展，综述不够全面
4. **讨论不深入**：仅罗列结果，缺乏深入分析
5. **写作不规范**：术语不统一，格式混乱
