# 文学 (Literature) 论文写作指南

## 学科特点
- 强调文本细读、理论框架、批评视角
- 重视原著阅读、版本考证、互文性
- 论证以阐释为主，逻辑以递进为佳

## 选题方向

### 中国古典文学
1. **诗词研究**
   - 唐宋词接受史
   - 诗歌意象系统
   - 版本与文本变异

2. **小说研究**
   - 明清小说叙事模式
   - 经典化过程（如《红楼梦》）
   - 小说与地域文化

3. **文论研究**
   - 古代批评术语现代阐释
   - 中西诗学比较
   - 文体演变

### 现当代文学
- 作家作品重读（经典化/去经典化）
- 文学思潮与制度（如"十七年文学"）
- 媒介与文学（网络文学、科幻）
- 性别与文学
- 地方性与世界性

### 比较文学与世界文学
- 翻译与接受（译介学）
- 形象学（异国形象建构）
- 世界文学体系
- 数字人文与文学研究

### 文艺理论
- 西方理论中国化
- 新媒介文艺理论
- 生态批评
- 后人类主义

## 论文结构模板

### 文本分析论文
```
1. 引言（问题缘起、文本选择、方法论）
2. 文献综述（研究史、争议焦点、本文切入点）
3. 理论框架（概念界定、分析工具）
4. 文本细读（结构、意象、叙事、语言）
5. 深层阐释（文化、历史、哲学维度）
6. 结论（新见、局限、延伸）
```

### 文学史论文
```
1. 问题与视角
2. 历史语境重构
3. 作家/作品定位
4. 文学现象分析
5. 文学史意义
6. 结论
```

### 比较文学论文
```
1. 可比性论证
2. 影响研究/平行研究/跨文明研究
3. 具体比较（主题、形象、文类）
4. 理论提升
5. 结论
```

## 写作要点

### 文本细读
- **语言层**：修辞、节奏、象征、互文
- **结构层**：叙事视角、时间处理、空间建构
- **深层**：意识形态、文化记忆、主体建构

### 理论运用
- 避免"理论+例子"的简单套用
- 理论要服务于文本阐释
- 可对话、修正、挑战理论
- 中西理论结合需有自觉

### 文献综述
- 梳理研究史（谁、何时、何观点）
- 指出未解决的问题或盲区
- 说明自己的位置（推进/修正/反驳）

### 论证方式
- 递进式：由表及里、由小见大
- 对比式：并置对照、凸显特质
- 历史式：历时梳理、共时定位

## 常见错误
1. **过度阐释**：脱离文本的过度发挥
2. **理论先行**：用理论切割文本
3. **感悟式批评**：缺乏分析，只有感受
4. **史料堆砌**：缺乏问题意识
5. **概念模糊**：核心术语未界定

## 工具推荐
- **古籍**：中国基本古籍库、爱如生、汉籍全文
- **现代文学**：中国现代文学馆、CNKI
- **外文**：JSTOR、Project MUSE、MLA International Bibliography
- **理论**：Stanford Encyclopedia of Philosophy
- **写作**：Word（文学常用）

## 投稿建议
- **顶级期刊**：《文学评论》、《文艺研究》、《中国社会科学》
- **专业期刊**：按时代/领域选择
- **理论期刊**：《文艺理论研究》、《文化与诗学》
- **海外期刊**：Modern Chinese Literature and Culture

## 查重注意事项
- 古诗词引用不计入（但需标注版本）
- 理论家观点引用需改写
- 作品情节概述用自己的话
- 研究史部分最易重复，需重新组织
- 避免大段引用（即使标注）
