# 工科通用论文写作指南

## 学科特点
- 强调问题驱动、方案创新、实验验证
- 重视可重复性、参数完整、边界条件
- 会议论文 + 期刊论文并重（顶会：IEEE系列/ACM系列）
- 图表质量要求高（工程图纸、仿真图、实物图）

## 研究类型

### 1. 设计研究
- **适用**：新系统/新结构/新算法设计
- **核心要素**：
  - 需求分析（功能/性能/约束）
  - 方案设计（架构/模块/接口）
  - 可行性论证（理论/仿真/原型）
  - 性能评估（对比/基准测试）
- **论文结构**：问题→方案→实现→验证→讨论

### 2. 实验研究
- **适用**：物理实验、性能测试、可靠性验证
- **核心要素**：
  - 实验平台（设备/环境/条件）
  - 实验方案（变量/水平/重复）
  - 数据采集（传感器/采样率/精度）
  - 结果分析（误差/不确定度/统计）
- **论文结构**：目的→方法→实验→结果→分析

### 3. 仿真研究
- **适用**：数值模拟、计算分析、虚拟验证
- **核心要素**：
  - 模型建立（几何/物理/数学）
  - 网格划分（类型/密度/质量）
  - 边界条件（载荷/约束/接触）
  - 求解设置（算法/收敛/精度）
  - 结果验证（实验对比/文献对比）
- **论文结构**：问题→建模→求解→验证→应用

### 4. 优化研究
- **适用**：参数优化、结构优化、调度优化
- **核心要素**：
  - 优化目标（单目标/多目标）
  - 设计变量（连续/离散/混合）
  - 约束条件（等式/不等式）
  - 优化算法（梯度/启发式/元启发式）
  - 收敛性分析（迭代曲线/稳定性）
- **论文结构**：问题→建模→算法→实验→对比

## 论文结构模板

### 本科毕业论文
```
1. 绪论
   - 研究背景（工程需求、技术现状）
   - 国内外研究现状（分类综述）
   - 研究目的与意义
   - 论文组织结构

2. 理论基础/相关工作
   - 核心概念定义
   - 基础理论推导
   - 现有方法总结（优缺点对比表）

3. 方案设计/方法提出
   - 总体架构（系统框图）
   - 详细设计（模块分解图）
   - 关键算法（伪代码/流程图）
   - 创新点说明

4. 实验/仿真/实现
   - 实验平台/仿真环境
   - 参数设置（完整列表）
   - 实验方案（对照组设计）
   - 实施过程（关键步骤）

5. 结果与分析
   - 主要结果（图表优先）
   - 对比分析（与现有方法）
   - 参数敏感性分析
   - 误差/不确定度分析
   - 讨论（机理解释）

6. 结论与展望
   - 主要贡献（1.2.3.）
   - 局限性
   - 未来工作
```

### 硕士/期刊论文
增加：
- 更详细的理论推导
- 更充分的实验验证（多场景/多数据集）
- 更深入的机理分析
- 更广泛的对比（SOTA方法）
- 复杂度分析（时间/空间）

## 图表规范

### 工程图纸
- **CAD图**：线型规范（粗实线/细实线/虚线/中心线）
- **尺寸标注**：完整、清晰、不遗漏
- **公差配合**：标注合理（IT等级）
- **材料标注**：牌号、状态、热处理
- **技术要求**：表面粗糙度、形位公差

### 仿真结果图
- **云图**：色标清晰、范围合理、标注单位
- **曲线图**：坐标轴标签、单位、图例、网格
- **矢量图**：箭头方向、大小比例、关键区域放大
- **对比图**：相同尺度、相同视角、相同参数

### 实物照片
- **分辨率**：300dpi以上
- **背景**：简洁、不干扰主体
- **标注**：关键部件指示、尺寸参照
- **多角度**：整体+局部+细节

### 系统框图/流程图
- **层次清晰**：系统级→模块级→单元级
- **接口明确**：信号流、数据流、控制流
- **标准符号**：符合IEEE/GB标准
- **颜色规范**：功能区分（输入/处理/输出/反馈）

## 公式与算法

### 公式规范
- **编号**：(1)、(2)、(3)...，右对齐
- **引用**："如公式(3)所示"
- **推导**：关键步骤不省略，引用定理需标注
- **符号**：首次出现定义，全文统一
- **单位**：SI单位，量纲一致

### 算法伪代码
- **格式**：结构化、缩进、注释
- **输入/输出**：明确参数、返回值
- **复杂度**：标注时间/空间复杂度
- **关键步骤**：加粗/注释说明

```
算法1：XXX算法
输入：参数1, 参数2, ...
输出：结果
1. 初始化...
2. for i = 1 to n do
3.   计算...
4.   if 条件 then
5.     更新...
6.   end if
7. end for
8. return 结果
```

## 工具推荐

### 建模与仿真
- **MATLAB/Simulink**：控制、信号、数值计算
- **ANSYS**：结构、流体、电磁、多物理场
- **SolidWorks/CATIA**：三维建模、装配、工程图
- **AutoCAD**：二维工程图、电气图
- **COMSOL**：多物理场耦合仿真
- **ABAQUS**：非线性分析、材料力学

### 编程与算法
- **Python**：数据分析、机器学习、自动化
- **C/C++**：高性能计算、实时系统
- **LabVIEW**：测控系统、虚拟仪器
- **PLC编程**：工业控制、自动化

### 数据可视化
- **Origin**：科学绘图、曲线拟合
- **Tecplot**：CFD后处理、云图
- **Paraview**：开源可视化、大规模数据
- **MATLAB**：内置绘图、自定义

## 常见错误
1. 参数设置不完整（缺少关键参数）
2. 边界条件不清晰（影响结果复现）
3. 图表质量差（分辨率低、标注不清）
4. 对比不公平（不同条件、不同数据集）
5. 误差分析缺失（不确定度未评估）
6. 创新点描述模糊（未与现有方法对比）
7. 理论推导跳跃（关键步骤省略）
8. 实验可重复性差（环境/设备未记录）
9. 结论过度推广（超出实验条件）
10. 工程图不规范（线型/标注/公差错误）
