# 心理学论文写作指南

## 学科特点
- 强调实验设计、统计严谨、理论验证
- 重视伦理审查、知情同意、动物福利
- 期刊论文为主（顶刊：Psychological Science/JPSP/JEP/Developmental Psychology）
- 预注册（Preregistration）越来越重要
- 开放科学（Open Science）趋势：数据/代码/材料共享

## 研究类型

### 1. 实验心理学
- **适用**：因果关系、认知机制、行为实验
- **设计类型**：
  - 被试间设计（Between-subjects）：不同被试接受不同处理
  - 被试内设计（Within-subjects）：同一被试接受所有处理
  - 混合设计（Mixed）：既有被试间也有被试内变量
- **关键要素**：
  - 自变量操纵（明确、有效、可重复）
  - 因变量测量（反应时、正确率、眼动、ERP、fMRI）
  - 混淆控制（随机化、平衡、掩蔽）
  - 功效分析（G*Power：f=0.25中效应，α=0.05，1-β=0.80）
- **报告规范**：
  - 假设预注册（OSF、AsPredicted）
  - 实验程序完整描述（可重复）
  - 排除标准透明（如反应时<200ms）
  - 贝叶斯分析补充（BF10）

### 2. 发展心理学
- **适用**：毕生发展、年龄差异、纵向追踪
- **设计类型**：
  - 横断设计：不同年龄组同时测
  - 纵向设计：同一群体多次测
  - 序列设计：横断+纵向结合
- **关键要素**：
  - 年龄分组（理论驱动：如皮亚杰阶段）
  - 测量等值（不同年龄工具可比）
  - 流失处理（MAR/MCAR检验、多重插补）
  -  cohort效应（时代背景差异）
- **特殊考虑**：
  - 儿童伦理：家长同意+儿童同意（7岁以上）
  - 发展适宜：任务难度、注意力维持
  - 社会期许：儿童更易迎合

### 3. 社会心理学
- **适用**：社会认知、态度、群体过程、人际关系
- **常用方法**：
  - 问卷法：量表测量（李克特5/7点）
  - 实验法：情境操纵（如阿希从众实验变式）
  - 现场实验：自然情境干预
  - 档案分析：历史数据、媒体内容
- **关键要素**：
  - 社会期许偏差控制（匿名、间接测量、IAT）
  - 样本代表性（WEIRD问题：西方、受过教育、工业化、富裕、民主）
  - 效应量关注（小效应d=0.2、中d=0.5、大d=0.8）
  - 重复实验（直接/概念/系统重复）

### 4. 临床心理学
- **适用**：心理障碍、干预效果、评估工具
- **设计类型**：
  - RCT：金标准，随机分配治疗组/对照组
  - 单被试实验：ABA/多基线设计
  - 准实验：自然分组、前后测
- **关键要素**：
  - 诊断标准（DSM-5/ICD-11）
  - 干预方案（手册化、保真度检查）
  - 结局指标（症状、功能、生活质量）
  - 脱落处理（ITT/PP分析）
- **伦理特殊**：
  - 脆弱人群保护（患者、儿童、老年人）
  - 最小风险原则
  - 数据保密（HIPAA/网络安全法）

## 实验设计

### 被试间 vs 被试内
| 维度 | 被试间 | 被试内 |
|------|--------|--------|
| 优点 | 无顺序效应、练习效应 | 个体差异控制、统计效力高 |
| 缺点 | 需要更多被试、个体差异混淆 | 顺序效应、练习效应、疲劳 |
| 适用 | 不同处理有永久影响 | 处理可逆、需要高统计效力 |
| 样本量 | 每组≥30（大效应） | 总样本≥20（大效应） |

### 准实验设计
- **不等组前后测**：无随机分组，需统计控制
- **中断时间序列**：多次观测，干预前后对比
- **回归间断**：基于连续变量的阈值分组
- **非等效对照组**：匹配而非随机

### 统计功效
- **计算工具**：G*Power、pwr包、WebPower
- **参数**：
  - 效应量（d=0.2小/0.5中/0.8大；f=0.1小/0.25中/0.4大）
  - α水平（0.05或0.01）
  - 统计功效（1-β=0.80或0.90）
  - 检验类型（双侧/单侧）
- **建议**：
  - 小效应：每组≥64（功效0.80）
  - 中效应：每组≥26
  - 大效应：每组≥16

## 统计方法

### 基础分析
- **t检验**：两组比较（独立/配对）
- **方差分析（ANOVA）**：多组比较
  - 单因素：一个自变量
  - 多因素：多个自变量+交互效应
  - 重复测量：被试内变量
  - MANOVA：多个因变量
- **卡方检验**：分类变量关联
- **相关分析**：Pearson/Spearman

### 高级分析
- **回归分析**：
  - 线性回归：连续预测→连续结果
  - Logistic回归：分类结果
  - 泊松回归：计数结果
  - 多层回归：嵌套数据（被试→班级→学校）
- **结构方程模型（SEM）**：
  - 验证性因子分析（CFA）：测量模型
  - 路径分析：结构模型
  - 多组比较：测量等值（ configural/metric/scalar）
- **多层线性模型（HLM/MLM）**：
  - 随机截距/斜率模型
  - 跨层交互
  - 3层及以上嵌套
- **潜增长模型（LGM）**：
  - 线性/非线性增长
  - 增长预测因子
  - 并行过程模型
- **生存分析**：事件发生时间

### 效应量报告
- **Cohen's d**：两组均值差（小0.2/中0.5/大0.8）
- **η²（eta-squared）**：方差解释比例（小0.01/中0.06/大0.14）
- **ω²（omega-squared）**：无偏估计
- **r²**：决定系数
- ** odds ratio（OR）**：Logistic回归
- **置信区间**：95% CI比P值更重要

## 量表使用

### 常用量表来源
- **APA PsycTests**：官方心理测验数据库
- **Mental Measurements Yearbook**：测验评价
- **期刊附录**：原始论文通常附完整量表
- **手册**：如BFI大五人格手册

### 翻译回译程序
1. 英文→中文（双语者翻译）
2. 中文→英文（独立双语者回译）
3. 对比原文与回译版本
4. 专家委员会讨论差异
5. 预测试（30-50人）
6. 信效度检验

### 信效度要求
- **信度**：
  - Cronbach's α ≥ 0.70（可接受）
  - 分半信度 ≥ 0.70
  - 重测信度（间隔2-4周）r ≥ 0.70
- **效度**：
  - 内容效度：专家评定
  - 结构效度：EFA/CFA、因子载荷≥0.50
  - 效标效度：与外部标准相关
  - 区分效度：AVE>相关系数²

## 伦理要求

### APA伦理准则（5项原则）
1. **受益与无害**：最大化受益、最小化伤害
2. **忠诚与责任**：专业标准、社会责任
3. **诚信**：诚实、准确、不欺诈
4. **公正**：公平对待、避免偏见
5. **尊重**：自主权、隐私、尊严

### 知情同意
- **要素**：研究目的、程序、风险、获益、保密、自愿、联系信息
- **特殊人群**：
  - 儿童：家长同意+儿童同意（7岁以上）
  - 认知障碍：法定代理人
  - 囚犯：额外保护
- ** deception研究**：事后解释（debriefing）

### 动物实验伦理
- **3R原则**：替代（Replacement）、减少（Reduction）、优化（Refinement）
- **IACUC审查**：方案审批、兽医监督
- **饲养条件**：环境丰富化、社会需求
- **终点设定**：人道终点、安乐死标准

## 论文结构模板

### 实验研究
```
1. 引言
   - 理论背景（核心概念）
   - 研究现状（文献缺口）
   - 研究问题与假设（H1a、H1b...）
   - 理论贡献与实践意义

2. 方法
   - 被试（招募、筛选、样本量、报酬）
   - 设计（2×3混合设计，自变量/因变量）
   - 材料/刺激（来源、编制、预测试）
   - 程序（步骤、随机化、掩蔽）
   - 数据分析计划（预注册链接）

3. 结果
   - 描述统计（M、SD、n）
   - 操纵检查（自变量有效）
   - 假设检验（ANOVA表、效应量、CI）
   - 附加分析（探索性、贝叶斯）
   - 图表（均值图、交互图）

4. 讨论
   - 假设验证总结
   - 理论解释（机制）
   - 与既往研究比较
   - 局限性（样本、方法、推广）
   - 未来方向（具体假设）
   - 结论（简明）

5. 补充材料（在线）
   - 完整问卷/刺激
   - 原始数据（OSF）
   - 分析代码（R/Python）
```

## 开放科学实践

### 预注册
- **平台**：OSF、AsPredicted、ClinicalTrials.gov
- **内容**：假设、设计、样本量、分析计划
- **类型**：
  - 标准预注册：数据收集前
  - 注册报告：期刊承诺发表（无论结果）
- **好处**：防止HARKing（假设后移）、提高可信度

### 数据共享
- **平台**：OSF、Figshare、Zenodo、GitHub
- **内容**：
  - 原始数据（去标识化）
  - 分析代码（可重复）
  - 研究材料（问卷、刺激）
- **许可**：CC0（推荐）、CC-BY

### 代码共享
- **要求**：可运行、有注释、有README
- **工具**：R Markdown、Jupyter Notebook
- **版本控制**：Git/GitHub

## 常见错误
1. 样本量不足（功效<0.80）
2. 多重比较未校正（Bonferroni/FDR）
3. 被试内设计无顺序控制（拉丁方/随机）
4. 效应量不报告（仅报P值）
5. 事后假设（HARKing）
6. 共同方法偏差（同源数据）
7. 量表信度低（α<0.70仍使用）
8. 因果关系过度推断（相关设计）
9. 文化差异忽视（WEIRD样本）
10. 伦理描述缺失（无法通过审稿）
