# 图书馆学论文写作指南

## 学科特点
- 强调信息服务、知识管理、文献组织
- 重视用户研究、技术应用、实践创新
- 研究方法多样：调查、实验、案例、系统开发
- 跨学科特性明显（计算机、管理、传播）

## 研究类型

### 1. 用户研究
- **适用**：信息行为、用户需求、服务评价
- **核心要素**：
  - 用户画像（年龄、职业、需求）
  - 行为分析（检索、利用、分享）
  - 满意度评价（服务质量、改进方向）
- **论文结构**：背景→方法→调查→分析→建议

### 2. 技术研究
- **适用**：数字图书馆、信息系统、数据管理
- **核心要素**：
  - 系统设计（架构、功能、技术）
  - 开发实现（编程、测试、部署）
  - 效果评估（性能、用户反馈）
- **论文结构**：需求→设计→实现→评估→结论

### 3. 理论研究
- **适用**：信息组织、知识管理、图书馆学理论
- **核心要素**：
  - 文献梳理（理论发展、研究现状）
  - 概念分析（定义、内涵、外延）
  - 理论建构（模型、框架、原则）
- **论文结构**：问题→文献→分析→理论→结论

## 学科细分

### 图书馆学
- **文献资源建设**：采编、馆藏发展、资源评价
- **信息服务**：参考咨询、学科服务、知识服务
- **阅读推广**：读书活动、阅读疗法、儿童阅读
- **图书馆管理**：战略规划、人力资源、绩效评估

### 档案学
- **档案管理**：收集、整理、鉴定、保管
- **档案信息化**：数字化、电子文件、数字档案馆
- **档案利用**：编研、展览、开放
- **档案保护**：修复、复制、环境控制

### 信息资源管理
- **知识管理**：知识组织、知识图谱、知识服务
- **数据管理**：数据治理、数据质量、数据安全
- **竞争情报**：信息采集、分析、应用
- **数字人文**：文本分析、数据可视化、数字出版

## 论文结构模板

### 调查研究型
```
1. 引言（研究背景、问题、意义）
2. 文献综述（研究现状、理论基础）
3. 研究设计（对象、方法、工具）
4. 调查结果（数据、图表）
5. 分析与讨论（发现、比较、解释）
6. 结论与建议（贡献、局限、改进）
```

### 系统开发型
```
1. 引言（需求背景、目标）
2. 需求分析（用户需求、功能需求）
3. 系统设计（架构、数据库、界面）
4. 系统实现（技术选型、关键代码）
5. 系统测试（功能测试、性能测试）
6. 结论（总结、展望）
```

## 写作要点

### 调查研究
- 样本选择（随机、分层、便利）
- 问卷设计（信度、效度）
- 数据分析（描述统计、推断统计）
- 结果呈现（图表、文字结合）

### 系统开发
- 需求分析（用户访谈、用例分析）
- 系统设计（架构图、ER图、流程图）
- 关键技术（算法、实现细节）
- 测试验证（测试用例、结果分析）

### 理论研究
- 文献梳理（系统性、批判性）
- 概念界定（清晰、准确）
- 逻辑推理（严密、有据）
- 理论贡献（创新、实用）

## 常见问题

1. **选题过大**：范围太广，难以深入
2. **文献综述薄弱**：缺乏系统梳理，遗漏重要文献
3. **研究方法不当**：方法与问题不匹配
4. **数据分析浅显**：仅描述统计，缺乏深入分析
5. **实践价值不明确**：建议空泛，缺乏可操作性
