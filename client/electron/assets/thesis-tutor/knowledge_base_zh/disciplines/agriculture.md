# 农学论文写作指南

## 学科特点
- 强调实践应用、田间实验、产量提升
- 重视实验设计、统计分析、推广应用
- 研究周期长（作物生长周期）
- 区域性强（气候、土壤差异）

## 研究类型

### 1. 田间试验
- **适用**：作物栽培、品种选育、植物保护
- **核心要素**：
  - 试验设计（随机区组、裂区设计）
  - 数据采集（产量、品质、抗性）
  - 统计分析（方差分析、多重比较）
- **论文结构**：目的→材料→方法→结果→讨论

### 2. 实验室研究
- **适用**：分子生物学、生理生化、土壤分析
- **核心要素**：
  - 实验方法（提取、检测、分析）
  - 数据处理（统计检验、图表）
  - 结果验证（重复、对照）
- **论文结构**：引言→材料→方法→结果→讨论

### 3. 调查研究
- **适用**：农业经济、农村发展、农业政策
- **核心要素**：
  - 调查设计（问卷、访谈）
  - 数据收集（样本、抽样方法）
  - 分析方法（描述统计、回归分析）
- **论文结构**：背景→方法→调查→分析→结论

## 学科细分

### 作物学
- **作物栽培**：种植制度、施肥技术、水分管理
- **作物遗传育种**：品种改良、杂交育种、分子育种
- **作物生理**：光合作用、营养代谢、逆境生理

### 植物保护
- **植物病理**：病害诊断、防治技术、抗病育种
- **农业昆虫**：害虫防治、天敌利用、综合治理
- **农药学**：药效试验、残留分析、安全评价

### 园艺学
- **果树学**：品种选育、栽培技术、采后处理
- **蔬菜学**：设施栽培、品质调控、安全生产
- **花卉学**：品种资源、繁殖技术、花期调控

### 农业资源与环境
- **土壤学**：土壤肥力、土壤改良、土壤污染
- **农业气象**：气候资源、灾害预警、气候变化
- **农业生态**：生态农业、循环农业、可持续发展

## 论文结构模板

### 田间试验型
```
1. 引言（研究背景、目的、意义）
2. 材料与方法（试验区、材料、设计、测定）
3. 结果与分析（产量、品质、抗性等）
4. 讨论（机理、比较、应用）
5. 结论（主要发现、建议）
```

### 实验室研究型
```
1. 引言（研究现状、目的）
2. 材料与方法（材料、试剂、方法）
3. 结果（数据、图表）
4. 讨论（机理、意义）
5. 结论（贡献、展望）
```

## 写作要点

### 田间试验描述
- 试验地点（经纬度、海拔、气候）
- 土壤条件（类型、肥力、pH）
- 试验材料（品种、来源、特性）
- 试验设计（处理、重复、小区面积）

### 数据呈现
- 产量数据（kg/亩或t/ha）
- 品质指标（蛋白质、淀粉等）
- 统计分析（F检验、LSD、Duncan）
- 图表规范（误差线、显著性标记）

### 推广价值
- 经济效益分析
- 技术可行性
- 区域适应性
- 推广建议

## 常见问题

1. **试验设计不规范**：缺乏对照、重复不足
2. **数据处理不当**：统计方法错误、显著性标记混乱
3. **讨论不深入**：仅罗列结果、缺乏机理分析
4. **推广价值不明确**：缺乏经济效益分析
5. **写作不规范**：术语不统一、格式混乱
