# 法学 (Law) 论文写作指南

## 学科特点
- 强调规范分析、案例研究、比较方法
- 重视法律条文、司法解释、判例
- 论证逻辑严密，注重"三段论"

## 选题方向

### 民法领域
1. **合同法**
   - 电子合同效力
   - 格式条款规制
   - 情势变更原则适用

2. **物权法**
   - 居住权制度实施
   - 农村土地经营权
   - 担保制度现代化

3. **侵权责任**
   - 网络侵权责任
   - 生态环境损害
   - 自动驾驶责任

### 刑法领域
- 人工智能刑事责任
- 网络犯罪治理
- 企业合规不起诉
- 轻罪治理与前科消灭

### 商法/经济法
- 平台经济反垄断
- 数据产权保护
- 证券集体诉讼
- 破产重整制度

### 国际法
- 数字贸易规则
- 国际投资仲裁
- 气候变化国际责任
- 网络空间国际法

### 理论法学
- 数字法治理论
- 算法治理
- 法律与人工智能
- 法典化研究

## 论文结构模板

### 规范分析论文（最常见）
```
1. 引言（问题意识、研究意义、方法论）
2. 现状描述（规范现状、司法实践、存在问题）
3. 比较研究（域外立法、国际公约、启示）
4. 理论分析（法理基础、价值权衡、原则冲突）
5. 制度设计（具体建议、条文设计、配套措施）
6. 结论
```

### 实证研究论文
```
1. 引言
2. 研究假设（理论推导）
3. 研究设计（案例选择、数据来源、变量）
4. 实证结果（描述统计、回归分析、稳健性）
5. 讨论（与理论对话、政策含义）
6. 结论
```

### 案例研究论文
```
1. 案例选择与意义
2. 案件事实梳理
3. 争议焦点归纳
4. 裁判理由评析
5. 类案比较
6. 规范建议
```

## 写作要点

### 法律论证
- **三段论**：大前提（规范）→ 小前提（事实）→ 结论
- **目的解释**：立法目的、体系解释、历史解释
- **比较方法**：功能主义比较（解决相同问题）
- **经济分析**：效率、成本收益、激励效应

### 文献引用
- **法条**：全称 + 条文号（如《民法典》第1165条）
- **判例**：案号 + 法院 + 裁判要点
- **学说**：学者 + 观点 + 出处
- **国际**：条约名称 + 条款 + 解释文件

### 案例分析
- 案由、当事人、审级
- 裁判要旨（法院观点）
- 学理评析（支持/反对/修正）
- 类案检索（指导案例、公报案例）

## 数据来源
- **法规**：国家法律法规数据库、北大法宝
- **案例**：中国裁判文书网、北大法宝、威科先行
- **学说**：CNKI、万方、HeinOnline（英文）
- **立法资料**：法律草案、审议报告、立法说明

## 常见错误
1. **法条引用错误**：条文号、版本（是否修订）
2. **案例过时**：已被改判或新法替代
3. **比较法误用**：简单移植，忽视制度背景
4. **价值判断空洞**："不公平"、"不合理"（需具体论证）
5. **忽视实务**：纯理论推导，脱离司法实践

## 工具推荐
- **法规检索**：北大法宝、威科先行、法律之星
- **案例检索**：中国裁判文书网、聚法案例、无讼
- **文献管理**：Zotero（支持法条、案例类型）
- **写作**：Word（法学常用）或 LaTeX
- **格式**：《法学引注手册》（2020）

## 投稿建议
- **法学三大刊**：《中国法学》、《法学研究》、《中国社会科学》（法学）
- **专业期刊**：按领域选择（《法商研究》、《政法论坛》、《法制与社会发展》）
- **实务期刊**：《人民司法》、《法律适用》（面向法官）

## 查重注意事项
- 法条原文不计入查重（但需标注）
- 司法解释原文需标注
- 案例描述用自己的话概括
- 比较法介绍（外国法）可接受一定重复
- 理论学说引用需改写并标注
