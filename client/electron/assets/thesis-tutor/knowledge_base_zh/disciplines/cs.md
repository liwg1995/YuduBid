# 计算机科学 (CS) 论文写作指南

## 学科特点
- 强调算法创新、系统实现、实验验证
- 重视代码开源、数据集、可复现性
- 会议论文 > 期刊论文（顶会：CVPR/ICML/NeurIPS/SIGCOMM/SOSP）

## 选题方向

### 热门领域
1. **人工智能/机器学习**
   - 大模型效率优化（推理加速、模型压缩）
   - 多模态学习（视觉-语言-音频融合）
   - AI安全与对齐（RLHF、红队测试）
   - 联邦学习与隐私计算

2. **系统与网络**
   - 云原生系统（Serverless、微服务）
   - 边缘计算与IoT
   - 网络安全（零信任架构、威胁检测）
   - 分布式系统一致性

3. **软件工程**
   - 代码智能（代码生成、缺陷检测）
   - DevOps与AIOps
   - 软件供应链安全
   - 低代码/无代码平台

4. **数据科学**
   - 时序数据分析
   - 图神经网络应用
   - 数据治理与质量
   - 实时流处理

### 选题评估标准
- **创新性**：新问题 or 新解法 or 新视角
- **可行性**：6-12个月可完成
- **价值性**：学术界 or 工业界认可
- **数据/代码**：是否有公开资源

## 论文结构模板

### 本科毕业论文
```
1. 引言（研究背景、问题定义、贡献概述）
2. 相关工作（分类综述，指出Gap）
3. 方法/系统设计（架构图、算法伪代码、流程图）
4. 实验/实现（数据集、指标、对比实验、消融实验）
5. 结果分析（图表、统计显著性、Case Study）
6. 讨论（局限性、未来工作）
7. 结论
```

### 硕士论文
增加：
- 理论基础（形式化定义、定理证明）
- 更完整的实验（多数据集、多基线、长时间运行）
- 系统部署（真实环境测试、用户研究）

## 写作要点

### 算法描述
- 使用伪代码（非真实代码）
- 时间/空间复杂度分析
- 收敛性证明（优化类）

### 实验设计
- 基线选择：经典方法 + SOTA
- 评估指标：Accuracy/F1/Latency/Throughput
- 显著性检验：t-test or Wilcoxon
- 消融实验：验证每个组件的必要性

### 图表规范
- 使用矢量图（PDF/SVG）
- 颜色对色盲友好
- 误差棒（多次运行）
- 表格三线表

## 常见错误
1. **实验不充分**：只有1-2个数据集，缺少对比
2. **过度声称**："首次提出"、"最优"（需有证明）
3. **代码不可复现**：缺少环境配置、随机种子
4. **Related Work 罗列**：要有批判性分析
5. **Introduction 空洞**：要具体说明解决了什么问题

## 工具推荐
- **实验管理**：Weights & Biases, MLflow
- **绘图**：Matplotlib, Seaborn, Plotly
- **代码版本**：Git + GitHub
- **写作**：Overleaf（LaTeX）
- **参考文献**：Zotero + Better BibTeX

## 投稿建议
- **会议**：关注 deadline，提前2个月完成
- **期刊**：审稿周期长，适合系统性工作
- **arXiv**：快速发布，建立优先权

## 查重注意事项
- 代码片段不计入查重（多数系统）
- 公式描述用自己的话
- 算法伪代码可接受一定重复
- 实验设置描述可标准化
