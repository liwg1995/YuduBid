# 考古学论文写作指南

## 学科特点
- 强调田野发掘、实物研究、历史重建
- 重视地层学、类型学、科技考古
- 研究周期长（发掘、整理、研究）
- 跨学科特性明显（历史、地质、生物、化学）

## 研究类型

### 1. 田野考古报告
- **适用**：遗址发掘、调查报告
- **核心要素**：
  - 地层描述（土质、土色、包含物）
  - 遗迹描述（灰坑、房址、墓葬）
  - 遗物描述（陶器、石器、骨器）
- **论文结构**：概况→地层→遗迹→遗物→分期→结语

### 2. 专题研究
- **适用**：器物研究、文化研究、年代学
- **核心要素**：
  - 资料收集（考古材料、文献）
  - 类型学分析（分型分式、演变序列）
  - 文化阐释（功能、意义、交流）
- **论文结构**：引言→材料→分析→讨论→结论

### 3. 科技考古
- **适用**：测年、成分分析、残留物分析
- **核心要素**：
  - 样品采集（代表性、保存状况）
  - 分析方法（C14、热释光、XRF）
  - 数据解释（年代、产地、工艺）
- **论文结构**：背景→样品→方法→结果→讨论

## 学科细分

### 史前考古
- **旧石器时代**：人类起源、石器技术
- **新石器时代**：农业起源、文明起源
- **青铜时代**：国家形成、早期文明

### 历史考古
- **夏商周考古**：都城、青铜器、甲骨文
- **秦汉考古**：帝陵、简牍、丝绸之路
- **魏晋南北朝考古**：墓葬、佛教遗存
- **隋唐宋元考古**：城市、瓷器、对外交流

### 专门考古
- **环境考古**：古环境、古气候、人地关系
- **动物考古**：动物骨骼、驯化、祭祀
- **植物考古**：植物遗存、农业、食谱
- **冶金考古**：矿冶遗址、金属器、技术

## 论文结构模板

### 田野报告型
```
1. 概况（地理位置、发掘经过）
2. 地层堆积（地层关系、分期依据）
3. 遗迹（灰坑、房址、墓葬等）
4. 遗物（陶器、石器、骨器等）
5. 分期与年代（文化序列、绝对年代）
6. 结语（主要收获、学术意义）
```

### 专题研究型
```
1. 引言（研究史、目的、方法）
2. 材料（来源、数量、状况）
3. 分析（类型学、统计、比较）
4. 讨论（功能、意义、交流）
5. 结论（主要观点、学术贡献）
```

## 写作要点

- 遗迹平剖面图

- 照片记录

### 类型学分析
- 分型分式标准
- 演变序列
- 典型器物
- 对比材料

### 年代学
- 地层依据
- 器物类型
- 测年数据
- 文献记载

## 常见问题

1. **地层描述不清**：土质、土色、包含物不详细
2. **类型学不规范**：分型分式标准不统一
3. **年代判断武断**：缺乏多重证据
4. **文化阐释空泛**：缺乏深入分析
5. **图版质量差**：照片模糊、线图不规范
