# 评审与答辩阶段详细操作手册（阶段⑤-⑦）

> 本文件为主 SKILL.md 的补充参考。当需要执行评审、格式检查或答辩准备时按需读取。

---

## 阶段⑤：评审修改

### 步骤 5.1：多维度评审

#### Phase 1：整体扫描
- 结构完整性（GB/T 7713.1-2006）
- 研究问题清晰度，全局印象
- 🔴/🟡/🟢 标注

#### Phase 2：逐章五维分析

| 维度 | 检查内容 | 标准 |
|------|---------|------|
| 学术质量 | 研究问题/创新性/方法论 | 专业学位侧重实践价值 |
| 写作质量 | 逻辑连贯性/论证严密性 | 每章有呼应 |
| 格式规范 | GB/T 7713.1 结构/图表/参考文献 | GB/T 7714-2025 |
| 数据结果 | 统计分析/图表质量 | 数据支撑结论 |
| 学术诚信 | 引用规范/数据真实性 | 无学术不端 |

#### 博士专项评审维度（当学位=博士时启用）

| 维度 | 检查内容 | 标准 |
|------|---------|------|
| **理论贡献层次** | 是增量补充、修正完善、还是颠覆现有理论？ | 博士需至少达到"修正"层次，明确说明贡献边界 |
| **文献覆盖完整性** | 是否遗漏关键流派、经典文献、最新顶刊（近3年）？ | 需覆盖国内外主流观点，对争议有回应 |
| **方法独创性/严谨性** | 方法是组合创新还是仅复制？样本量是否足够稳健？ | 博士建议：量化N>300或质性饱和+多重三角验证 |
| **论证深度** | 是否仅停留于现象描述，缺乏机制分析？ | 需打开黑箱，讨论"为什么"而非"是什么" |

> 在评审报告模板中，若用户为博士，则在"整体评分"后增加一行"理论贡献评分：{}/10"，并在"🔴严重问题"中优先标注理论贡献不足、文献遗漏等问题。

#### Phase 3：跨章一致性
- 研究问题 ↔ 结论对应
- 方法 ↔ 数据对应
- 引用 ↔ 文献列表一致

#### Phase 4：多视角评审
- **贡献视角**：研究贡献是否清晰？（MPA 重点：实践价值）
- **严谨性视角**：方法可靠？论证严密？
- **写作视角**：表达清晰？逻辑流畅？
- **编辑视角**：格式规范？图表标准？

#### Phase 5：七维漏洞扫描
选题价值 / 理论深度 / 方法严谨性 / 数据分析 / 写作表达 / 格式规范 / 学术诚信

### 步骤 5.2：评审报告模板

```
# 论文评审报告

## 整体评分
- 学术质量：{}/10 | 写作质量：{}/10 | 格式规范：{}/10
- 数据与结果：{}/10 | 学术诚信：{}/10 | 综合：{}/10

## 🔴 严重问题（{N}条）
[N 条具体问题]

## 🟡 建议改进（{N}条）
[N 条具体问题]

## 🟢 良好表现（{N}条）

## 修改优先级
1. {最优先} 2. ... 
```

### 步骤 5.3：Sprint 式迭代修改

1. 创建 Backlog（按严重度+难度分类）
2. 优先级：🔴易改 > 🔴难改 > 🟡易改
3. 每轮聚焦 3-5 个问题
4. 修改 → Review → Gate Check → 全部🔴解决？→ 下一阶段

## 阶段⑥：格式排版与查重

> 🟠 扩展模块：查重和 AI 率检测需外部工具（知网/维普查重系统、AI 检测工具等）。本技能提供格式检查清单、降重策略和降 AI 率改写服务，具体查重需用户在学校系统执行。

### 步骤 6.1：格式检查清单

**📐 格式**：标题层级、字体字号、页眉页脚、页码、图表编号连续

**📚 引用**：GB/T 7714-2025 格式统一、正文引用↔参考文献双向一致、数量达标（本 15-30/硕 30-50）

**🔍 逻辑**：各章呼应、结论回应问题、方法支撑结论

**⚠️ 常见硬伤**：摘要超字数、关键词不规范、图表无编号、致谢导师名错误、目录标题不一致

### 步骤 6.2：降重策略

| 有效性 | 策略 |
|-------|------|
| ✅ 最有效 | 句式重构 + 加数据/案例支撑 |
| ✅ 有效 | 图表替代文字 |
| ❌ 无效 | 同义替换、中译英再译回、截图 |

参考：<15% 安全，15-25% 需修改，25-40% 必须改（以学校为准）

### 步骤 6.3：AI 率降低（系统化策略）

#### 第一步：识别AI特征词汇

| AI常用套话 | 自然化替换示例 |
|-----------|---------------|
| 值得注意的是 | 需要强调的是 / 一个关键发现是 / 特别地 |
| 综上所述 | 综合以上分析 / 简而言之 / 由此可知 |
| 此外 | 同时 / 另外（尽量少用，直接并列） |
| 然而 | 但 / 不过 / 相反 |
| 首先…其次…最后 | 采用平实序号或省略，直接叙述 |
| 在当今XXX背景下 | 直接切入：XXX问题导致… |
| 本文旨在 | 直接写"本文分析…" |

#### 第二步：段落级重构（而非词汇替换）

- **变"总结式"为"论证式"**：不要最后一句总括，要把结论融入推理过程中。
- **增加批判性评价**：在引用他人观点后加入"这一解释的局限在于…""但XXX对此提出异议"。
- **插入具体细节**：将"调查显示很多人同意"改为"487份问卷中，67.3%的受访者选择了'同意'，其中基层科员占比最高（82%）"。
- **调整句型节奏**：长短句交替。AI偏好中长句（15-25字），可主动插入短句（5-8字）打断节奏。

#### 第三步：注入个人学术声音

- 使用"笔者认为""从本研究的实践角度看""数据进一步揭示"等主观但不失学术的短语。
- 在方法论和讨论部分，明确写出作者决策过程："本文选择X方法而非Y方法，因为…""在编码过程中遇到了Z类困难，处理方式是…"。
- 避免全篇被动语态，适当使用"我们""本研究"作为主语（尊重学科惯例）。

#### 自然化改写对照示例

| 原文（AI风格） | 改写后（自然风格） |
|--------------|------------------|
| 值得注意的是，本研究的结果与以往研究存在一定程度的一致性。 | 本研究结果与Wang等（2021）一致：数字化转型均提升了服务效率。但不同的是，本文发现这种提升在基层窗口更为明显。 |
| 综上所述，本文认为组织支持是影响员工创新的关键因素。 | 组织支持有多重要？数据分析给出明确答案：控制其他变量后，支持每提高1分，创新行为增加0.42分（p<0.001）。基层管理者应正视这一杠杆效应。 |
| 此外，年龄、工龄等人口学变量也对创新行为产生显著影响。 | 年龄和工龄同样发挥作用。工龄超过15年的员工，创新得分显著低于工龄5年以下的群体（t=3.21，p<0.01）。 |

#### 第四步：改后对比检测

完成改写后，建议：
1. 使用第三方AI检测工具（如GPTZero、Turnitin AI检测）对比修改前后分数。
2. 若仍高于学校要求（通常<15%），返回第二步，对高亮段落进行更激进的重构：改变例子、调整论述顺序、加入自己的总结表格。

## 附录：团队协作与版本管理

> 当论文涉及导师多轮批注、多人合写或持续修改时启用。

### 导师批注多轮迭代

**工作流**：
```
初稿 v1 → 导师批注 → AI 解读反馈 → 生成修改方案 → 确认后执行 → v2 → 导师再批注 → ...
```

**版本命名规范**：`论文_v{N}_{日期}_{改动摘要}.docx`（如 `论文_v3_0610_修改文献综述.docx`）

**批注追踪**：每次修改后生成《修改对照表》：

| 编号 | 导师意见 | 原段落 | 修改后 | 修改类型 |
|------|---------|--------|--------|---------|
| 1 | "论证不充分" | {原文} | {修改文} | 补充论据 |
| 2 | "格式不对" | {原文} | {修改文} | 格式调整 |

### Word 审阅模式建议

- 导师用"修订模式"批注 → 学生逐一回应"接受"/"拒绝"
- AI 辅助：将导师批注截图或文字粘贴给 AI，AI 输出回应话术和修改建议
- 最终版本关闭修订，只保留"干净版"提交

### 多人合写场景

- 分工明确：每章标注负责人
- 统一格式：全员用同一模板（由本技能生成）
- 汇总合并：由本章负责人收集各人稿件，AI 辅助做风格统一和衔接润色

### 定稿封存

每轮大改后存档旧版本（不要覆盖），保留回滚能力。

## 阶段⑦：答辩与毕业

### 步骤 7.1：PPT 框架

| 页码 | 内容 | 时间 | 要点 |
|------|------|------|------|
| 1 | 封面 | 0:00 | 题目+姓名+导师 |
| 2 | 研究背景 | 1:30 | 具体问题切入 |
| 3 | 研究目的与意义 | 1:00 | 现有研究缺什么，本文补什么 |
| 4 | 研究方法 | 1:30 | 方法理由+数据来源 |
| 5 | 研究结果 | 2:30 | 核心发现，图/表呈现 |
| 6 | 结论与展望 | 1:00 | ≤3 点结论 |
| 7 | 致谢 | 0:30 | 简短 |

时间：本 5-8min / 硕 10-15min / 博 20-30min

### 步骤 7.2：自述稿

开场白→研究背景→研究方法→研究结果→结论，按时间分段。

### 步骤 7.3：高频答辩问题库

- 方法质疑："样本量够吗？""为什么用这个方法？"
- 概念问题："这个'XXX'怎么定义的？"
- 数据来源："数据从哪来的？"
- 结论夸大："你说效果显著，怎么证明？"
- 创新性质疑："和已有 XX 研究有什么不同？"
- 局限问题："有什么局限？"

每条附回答策略。

### 步骤 7.4：模拟答辩

1. AI 扮演答辩委员提问 3-5 个问题
2. 用户回答
3. AI 点评：✅好的 + ❌需改进 + 💡可补充
4. 费曼检验：核心发现一句话说清？方法理由 30 秒解释？创新点对比句式表达？

优先问薄弱环节，至少 1 个"局限"类问题，MPA 类至少 1 个假设相关问题。

### 步骤 7.5：答辩技巧

语速 70%、轮流看每位老师、不会就说"思考不够深入，下来继续研究"、PPT 只说要点、提前计时演练。

### 步骤 7.6：终审清单

必查：论文终稿、PPT、自述稿、原创声明、封面信息、目录一致性、图表编号、参考文献格式、结论回应问题、数据有来源、导师名正确、PPT 演练 3 遍、自述计时、问题准备完毕、精读论文至少 1 遍。
